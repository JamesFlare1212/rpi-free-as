## Course Description

### Additional Course Description :

Introduction to the basic concepts of computer and communication networks, like flow control, congestion control, end-to-end reliability, routing, framing, error-recovery, multiple access and statistical multiplexing. In-depth presentation of the different networking layers, with emphasis on the Internet reference model. Protocols and architectures such as the TCP, IP, Ethernet, wireless networks etc. are described in order to illustrate important networking concepts. Brief introduction to quantitative analysis and modeling of networks.

## Course Content

### Content Details:

**Specific topics** to be covered in this course:  
• Introduction to layered architectures and protocols  
• Packet delay types and delay analysis using space-time diagrams  
• Application layer protocols: HTTP, FTP, SMTP and DNS  
• Principles of reliable data transfer  
• Internet transport protocols - TCP and UDP  
• IP addressing  
• Routing algorithms: link-state and distance-vector  
• Internet routing protocols: RIP, OSPF and BGP  
• Queuing delay and occupancy analysis for packet networks  
• Packet error detection and correction  
• Multi-access mechanisms: Aloha and CSMA/CD  
• Ethernet link layer technology and LANs  
• Analysis of Wireshark packet traces  
• Socket programming using UDP

### Course (Student) Learning Outcomes Assessment Measures:

### **S****tudent Learning Outcomes:**

1. Understand how space-time diagrams can be used to calculate end-to-end packet delays in a communication network.
2. Understand how different application layer protocols like HTTP, FTP, SMTP and DNS work.
3. Understand the principles of reliable transfer of data and congestion control and how these functions are implemented in transport layer protocols like TCP and UDP.
4. Understand addressing conventions and routing algorithms used in the Internet.
5. Understand fundamentals of queuing theory, and how they can be used in analyzing average delay and buffer requirements at routers.
6. Understand basic multi-access communication protocols, and their implementations in link layer standards/technologies like Ethernet and WiFi.
7. Analyze Wireshark traces to understand how and application and transport layer protocols work.
8. Building an application over UDP using socket programming.

### Additional Academic Integrity Course Policy and Penalty Information:

Student-teacher relationships are based on trust. Acts which violate this trust undermine the educational process. Violations of academic integrity will not be tolerated by your classmates, teaching assistants, or the instructor. Please refer to the *Rensselaer Handbook* for definitions of various forms of academic dishonesty and the applicable penalties. We take cheating very seriously; you can expect to be punished for violations of academic integrity.

Submission of any assignment that is in violation of this policy will result in a grade of zero in that assignment. Multiple violations may result in a grade of F in the overall course, and/or be reported to the Dean of Students Office.

If you have any question concerning this policy before submitting an assignment, please ask for clarification. In general, while discussions with your classmates are allowed (and encouraged!) for homeworks, the work submitted for grading must be entirely the student’s work. A similar policy applies to the programming assignment as well. For exams, no information exchange with anyone (other than the instructor) is allowed.
