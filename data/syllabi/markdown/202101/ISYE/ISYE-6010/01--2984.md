## Course Description

### Additional Course Description :

This course in Applied Regression is based on a first principles approach to the subject, where the emphasis is on understanding and not on algebra. We will cover applications of regression and important topics such as the assumption behind regression, cateforical predictors, linear and non-linear regression, and interactions and moderators.

## Course Goals

### Goals:

Upon completion of this course, the student will be able to:

1. Use the mathematical language of regression to describe the structure of a model of a process.
2. Design a regression model to meet desired needs within a realistic constraints such as economic, environmental, social, political, ethical, health and safety, manufacturability and sustainability.
3. Identify different types of factors, response variables and regression models.
4. Use the R statistical package to design and perform the analysis of a regression problem.
5. Perform a regression analysis and interpret the results.

The purpose of the four course projects is to get hands-on experience with a current regression topic, using one of the large datasets listed above. A standardized write up (to be defined) of each project will be required. The four projects will be on Simple Linear Regression; Multiple Regression, Assumptions about Regression; and Categorical or Logistic Regression.
