## Course Description

### Additional Course Description :

This course provides skills to apply econometrics to diverse economic topics. Econometric methods

are developed for tools such as instrumental variables, regression discontinuity, difference-indifferences

method, quantile regressions, and spatial regressions. Methods to identify causal effects

are emphasized. Students do hands-on data work that puts to use these econometric tools.
