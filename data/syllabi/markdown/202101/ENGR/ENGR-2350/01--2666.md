## Course Description

### Additional Course Description :

Engineering laboratory introduction to the microprocessor as an embedded element of engineering systems. Students simultaneously develop the hardware and software of one or more target systems during the semester. Topics include concepts and practices of microcontroller hardware and software for command, sensing, control, and display. Specifically, this includes control of dynamic systems and sensor interfaces; analog-digital conversion; parallel input/output; driver circuits, modular programming, and subsystem integration.

## Course Goals

### Goals:

This course is designed to provide students with basic understanding on what embedded systems are, how they work, and the tools to build rudimentary implementations. This includes development of skills associated with algorithm development, procedural programming, and debugging and troubleshooting, with a fairly strong emphasis on troubleshooting.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Be able to design interface hardware and software to sense, display, command, and control simple engineering processes.
- Be able to write software for a real-time embedded control system.
- Be able to prototype, implement, and debug the hardware for an embedded control system.
- Understand the basic operation of microcontrollers and their role in embedded control systems
- Understand the role of sensors and actuators and how they are applied to systems.
- Understand and be able to use the laboratory voltmeters and logic probes required to build and troubleshoot these systems. In this Online/Hybrid mode, experience with these tools will be provided via instructor lecture.

### Additional Academic Integrity Course Policy and Penalty Information:

All students will submit work individually for all assignments in this course. However, interaction between students is allowed and encouraged; however, the work (code or otherwise) produced by each student must be their own. During quizzes and exams, students are explicitly forbidden from communicating with any person, excluding the course staff.  
Students in this course should be aware that the Collaboration, Copying, and Plagiarism apply to the source code generated by each student towards the completion of the homeworks and laboratories. Tools exist to detect similarities between source code files and the staff reserves the right to employ such tools to deter source code based academic dishonesty. Any assignments that have been identified as violating the Academic Integrity policy will be assigned a 0 for all parties involved, with multiple violations or egregious violations resulting in immediate student failure and referral to the Dean of Students.
