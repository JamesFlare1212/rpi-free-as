## Course Description

### Additional Course Description :

This course goes far beyond the classical statistical methods, such as linear regression, that are introduced in ECON4570/6560 (Econometrics/Introduction to Econometrics). It aims to provide an overview to such modern non-linear methods as Generalized Additive Models, Decision Trees, Boosting, Bagging and Support Vector Machines as well as more classical linear approaches such as Logistic Regression, Linear Discriminant Analysis, K-Means Clustering and Nearest Neighbors. This course will cover all of these approaches in the context of Marketing, Finance and other important business decisions.

## Course Text(s)

### Text Details:

Gareth James, Daniela Witten, Trevor Hastie, and Robert Tibshirani, *Introduction to Statistical Learning with Applications in R*, Springer, 2013.

## Course Goals

### Goals:

At the end of this course you should have a basic understanding of how all of these learning methods work and be able to apply them successfully in real business situations.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Students who successfully complete this course should be able to: (1) develop a solid theoretical background in these popular statistical learning techniques. (2) demonstrate an ability to implement the techniques learned in the course. (3) demonstrate an ability to critique empirical statistical learning studies in economics. (4) demonstrate an ability to carry out statistical learning analysis independently.

### Course (Student) Learning Outcomes Assessment Measures:

Assignments:  
(i) Five or Six Problem sets  
(ii) A Midterm Exam  
(iii) A Take Home Empirical Project, in which you are required to carry out statistical learning analysis using R on a research topic given and present your findings in a research report (about 2000 words).
