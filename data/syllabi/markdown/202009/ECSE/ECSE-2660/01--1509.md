## Course Description

### Additional Course Description :

Quantitative basis of modern computer architecture, processor design, memory hierarchy, and input/output methods. Layered operating system structures, process and storage management. Layered network organization, network protocols, switching, local and wide area networks. Examples from Unix and the Internet.

## Course Text(s)

### Text Details:

- **Title:** *Computer Organization and Design,* 5th edition, **Authors:** David Patterson and John Hennessy, **Publisher:** Morgan Kaufmann

- **Title:** Operating System Concepts, 9th edition, **Authors:** Abraham Silberschatz, Peter Baer Galvin, Greg Gagne, **Publisher:** John Wiley & Sons

## Course Goals

### Goals:

- Understand the basic design principle of modern computer architecture
- Understand the basic design principle of modern operating systems and networking systems

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- a knowledge of basic building blocks of computer architecture, and an ability to evaluate its performance and benchmarks
- a knowledge of instruction set architecture and microprocessor arithmetic
- an ability to design and compare performance of single-cycle and multi-cycle processor architectures
- an ability to design and evaluate performance of a pipeline processor architecture
- an ability to design and evaluate performance of memory hierarchies including cache, virtual memory, main memory and storage devices
- a knowledge of operating systems structure
- a knowledge of operating systems procedural calls and process management
- an ability to perform a performance comparison of operating systems process scheduling
- a knowledge of computer networks reference layering and performance metrics

### Course (Student) Learning Outcomes Assessment Measures:

In-class activities, homework, exams
