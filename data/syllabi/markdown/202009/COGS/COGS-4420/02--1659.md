## Course Description

### Additional Course Description :

This course introduces students to basic concepts and methods of Artificial Intelligence (AI) as applied to computer games. This course overlaps with other introductory AI courses on many topics. However, the emphasis will be put on applying these techniques to digital games. The topics we will discuss in this class include movement, path finding, formation, decision making, learning, tactical and strategic reasoning, AI for humanlike characters, etc. This course will take the form of a combination of lectures, active learning and presentations by students, class discussions, and independent study.

## Course Content

### Content Details:

These are the topics I hope to cover during the semester:

- Introduction
- Steering and Movement Algorithms
- Unity Basics
- Constant Steering
- Collision Avoidance
- Complex Steering, Flocking
- Arbitration and Formation
- Pathfinding
- The A* Algorithm and its variations
- Decision-making (several parts)
- Planning Algorithms
- The Blackboard Architecture (theory only)
- Tactics, Tactical Analysis, Tactical Pathfinding
- Coordinated Action
- Board Games (several parts)
- Learning (several parts, time permitting)
- Reinforcement learning (time permitting)

The assignments will be designed around our progress with these topics. In many cases, you will be able to download a template Unity project that sets up the assignment, and your major effort will be to supply the AI needed for it.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Demonstrate essential low-level kinematic and dynamic steering behaviors in NPCs in a working sample game framework.
- Demonstrate refinements to kinematic and dynamic steering behaviors such as collision detection and obstacle avoidance in a working sample game framework.
- Demonstrate basic pathfinding (A-star) in a working sample game framework.
- Demonstrate more complex flocking and steering behaviors in a working sample game framework.
- Demonstrate several basic decision-making algorithms such as finite state machines in a working sample game framework.
- Demonstrate usage of Behavior Trees in a substantial sample game framework.
- Demonstrate a turn-based search tree algorithm in a working board game framework.
- Demonstrate basic tactical reasoning in a pencil-and-paper exercise.

### Course (Student) Learning Outcomes Assessment Measures:

Each assignment may contain multiple parts. Unless specified otherwise, all assignments are to be completed individually.  
For programming assignments (which is most of them), you need to make your project ready to compile and run, clearly document your code, and supply a readme file. The readme file should describe the project, list and describe the included files and the main functions, and explain why you think your algorithm will work for the problem. This doesn’t have to be long, especially if you’ve taken pains to document your code as well.  
Also document any “gotchas” I need to be aware of in getting your AI demo to run. The surest way to lose points on an assignment is when you make me have to chase down weird bugs, incompatibilities and the like trying to get your project to work.
