## Course Description

### Additional Course Description :

This is an undergraduate introductory course covering basic concepts and skills in engineering communication. Topics include technical writing, project planning and proposal writing, data visualization, system modeling and simulation, engineering graphics and CAD, and effective uses of software tools.

## Course Text(s)

### Text Details:

NONE

## Course Goals

### Goals:

1. Understanding 3-D space and parametric 2-D sketching.
2. General solid creation.
3. Standard documentation practices.
4. Data Integrity and responsibility.
5. Prepare the outline of a technical document effectively using MS Word™.
6. Generating effective graphs/charts from a set of data using MS Excel™.
7. Develop and organize a small project plan.
8. Generate effective formats for technical slides.
9. Organize the logistics of an effective meeting.
10. Describe and use NI LabView™ to visualize the behavior of a system.
