## Course Description

### Additional Course Description :

In this intensive studio production course, students work in interdisciplinary teams to create short digital games using multiple game engine technologies and a variety of creative design prompts. Developing video games takes a myriad of talents: art, programming, design, and most importantly, the ability to work in a team and communicate with others.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Students will have learned the basics of using multiple game development engines.
- Students will have created 2D and 3D games in interdisciplinary teams.
- Students will have applied game design principles in developing games in response to creative prompts.
- Students will demonstrate effective use of utilize version control and project management software in game development.
- Students will have developed collaboration skills with an emphasis on the remote-team context

### Course (Student) Learning Outcomes Assessment Measures:

- Introduction - Godot individual 10%
- Project 1 (Godot) 30%
- Project 2 (Unity) 30%
- Project 3 (Unreal Engine 4) 30%

## Grading Criteria

### Criteria Details:

Collaboration/communication  
○ How well did you work together as a team?  
○ Assessed via in-class discussion, Perforce, Basecamp

○ How much time and effort was put in?  
○ Assessed via playing the game and Perforce  
Technical accuracy  
○ Does the game play cleanly and well?  
○ Did the team use version control correctly? *While this is often a direct responsibility of programming, everyone on the team is held responsible for this.  
○ Assessed via playing the game and Perforce  
Efficiency  
○ How much progress was made during the sprint?  
○ Was progress consistent and substantial?  
○ Assessed via playing the game, Perforce, Basecamp

## Policies

### Attendance Policy:

Attendance is mandatory. You are a member of a team, and constant communication with your team is necessary. This class features an intense workload, as complete games are very difficult to make, and you'll be working within a highly compressed timespan. You will spend more time with your team outside of the classroom than within. If you cannot attend class for some reason, you must email both instructors with a written excuse or your grade for the associated project will be affected and you may be subject to failing the course.

## Other Course-Specific Information

### Additional Course Information:

# Software

The course is structured primarily around 3 team projects, each using a different game engine. There are many game engines in use throughout the industry, some publicly available, others proprietary. These are selected to demonstrate a variety of approaches to game development. The engines for this semester will be:

- Godot Engine
- Unity
- Unreal Engine

We will use online tools and platforms for collaboration, version control, and project management, including:

- Helix Perforce
- Basecamp
- Discord
- WebEx

Additionally, you will use other software as appropriate for creating game assets - images, 3D models, animations, audio files, etc. We will cover some of these tools in class, but you may use other ones. Software we will cover includes:

- Maya
- Substance Painter
- Blender
- Krita
