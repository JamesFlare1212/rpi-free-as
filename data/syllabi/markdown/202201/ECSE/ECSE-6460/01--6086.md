## Course Description

### Additional Course Description :

Tools and methods for the analysis and design of linear multivariable feedback systems. Topics include the connection between frequency domain and state space models and methods, model identification, model reduction, model uncertainty and closed loop performance, convex analysis and design methods, optimal controller synthesis using H2, H-infinity, and structured singular value criteria.

## Course Text(s)

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- • Design and analyze dynamic models of multivariable linear systems including mechanical and electrical systems.
- • Understand basic principles of feedback; disturbance rejection, robustness to parameters, tracking accuracy for multivariable linear systems.
- • Master multivariable linear feedback control design and analysis techniques, frequency response, and state-space.
- • Build and analyze models and design multivariable feedback controls that achieve design requirements.

### Course (Student) Learning Outcomes Assessment Measures:

The learning outcome will be assessed based on ten homework assignments and three tests. A student who is proficient with the course materials well will be able to score over 75% of the maximum score.
