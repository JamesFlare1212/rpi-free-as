## Course Description

### Additional Course Description :

This is a 4-unit junior-level statistical analysis course. The primary objective of this course is to introduce various statistical topics and learn to solve statistical problems using R. These topics include basic concepts such as sampling distribution, point estimation, confidence intervals, and hypothesis testing; regression methods such as simple and multiple regression, selection procedures, regression diagnostics, residual analysis, stepwise regression, and analysis of variance. This course will make extensive use of statistical software, R. (4.0 credits)
