## Course Description

### Additional Course Description :

Every dataset has a story to tell, and this class equips students with the tools to uncover those stories. The course develops students’ ability to ask critical questions about their data in order to better understand it. Students will run tests to identify data problems and will learn how to take corrective actions. In addition, the course covers important parametric and non-parametric tests, and discusses their benefits and limitations in a big data world. By the end of the course, students will have developed the ability to think statistically, apply a range of analytical techniques, and transform raw data into meaningful insights.

## Course Goals

### Goals:

1\. Explore and describe large datasets to identify interesting questions and trends

2\. Work with software to conduct data analysis (Python programming language at an

introductory level)

3\. Conduct statistical tests and be able to infer conclusions from those tests

4\. Visualize data with software

## Course Content

### Content Details:

- **Introduction to Data Science**
  - The data science workflow
  - Types and sources of data
  - From research questions to data-driven analysis
- **Exploring and Describing Data**
  - Data types and structures
  - Descriptive statistics
  - Distributions and summary measures
  - Exploratory data analysis (EDA)
- **Data Visualization**
  - Principles of effective visualization
  - Choosing appropriate charts and graphical representations
  - Identifying patterns, trends, and outliers
  - Communicating insights through visualization
- **R and RStudio for Data Science**
  - R/RStudio environment
  - Data manipulation and transformation
  - Data visualization in R
  - Reproducible data analysis
- **Python and Google Colab for Data Science**
  - Python fundamentals for data analysis
  - Working with data using Python
  - Data manipulation and visualization
  - Notebook-based analytical workflows
- **Data Collection, Cleaning, and Preparation**
  - Importing data from different sources
  - Missing values and duplicate observations
  - Data filtering, merging, and reshaping
  - Preparing raw data for analysis
- **Statistical Analysis and Regression**
  - Relationships among variables
  - Correlation and covariance
  - Simple and multiple linear regression
  - Model interpretation and evaluation
- **Time-Series and Financial Data Analysis**
  - Working with time-indexed data
  - Returns and stock-price data
  - Trends, volatility, and temporal dependence
  - Applications of data science to financial data
- **Introduction to Machine Learning**
  - Prediction versus explanation
  - Training and testing data
  - Model selection and out-of-sample evaluation
  - Regression and classification methods
  - Overfitting and regularization
- **Data Science and Artificial Intelligence**
  - Relationship among data science, machine learning, and AI
  - Introduction to generative AI and large language models
  - Using AI tools in the data science workflow
  - Responsible and effective use of AI
- **Communicating Data-Driven Results**
  - Interpreting analytical results
  - Presenting tables and figures
  - Translating analysis into actionable insights
  - Data storytelling and presentations
- **Applied Data Science Projects**
  - Formulating a data science question
  - Obtaining and preparing data
  - Selecting appropriate analytical methods
  - Conducting reproducible analysis
  - Presenting and communicating findings
