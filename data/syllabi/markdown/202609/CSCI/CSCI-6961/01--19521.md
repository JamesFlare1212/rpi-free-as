## Course Description

### Additional Course Description :

Information theory was invented by Claude E. Shannon in 1948 as a mathematical theory for communication but has subsequently found a broad range of applications.  
Part I: The first one-third of the course covers the core concepts of information theory, including entropy and mutual information, and how they emerge as fundamental limits of data compression and communication. A number of machine learning applications in which information measures play central roles will be discussed in detail.  
Part II: The second one-third will focus on source coding and its wide range of applications in machine learning.  
Part III: The last one-third will focus on the applications of information theory to high-dimensional statistics and data analytics.

## Course Goals

### Goals:

On completion of this course, students should be sufficiently familiar with the theoretical basis, formal representation, computational methods, notation, and vocabulary of information theory to be able to analyze and design communication systems, high-dimensional statistical inference, and machine learning applications.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Be able to analyze the entropy of given random variables and establish the fundamental properties of entropy and mutual information. Be able to analyze the capacity of discrete memoryless channels. Be able to form detection decision rules for inference from high-dimensional data. Be able to form estimation rules for inference from high-dimensional data. Be able to apply information theory to machine learning.
