## Course Description

### Additional Course Description :

This course involves a study of the methods used to extract and deliver dynamic information on the World Wide Web. The course uses a hands-on approach in which students actively develop Web-based software systems. Additional topics include installation, configuration, and management of Web servers. Students are required to have access to a PC on which they can install software such as a Web server and various programming environments.

## Course Text(s)

### Text Details:

The reading materials will be tailored to provide the needed conceptual background for the various technologies examined. Links to the required readings will be available via the LMS and/or course Github.

## Course Goals

### Goals:

By the end of the course, students will be able to:

1. Explain how a full-stack web application works—from the browser to the server, database, and network.
2. Select and justify appropriate technologies, architectures, and design patterns.
3. Build effective front-end experiences using HTML, CSS, JavaScript, and progressive enhancement.
4. Develop, integrate, and troubleshoot application back ends and web services.
5. Identify common web security risks and apply protections such as input validation, secure authentication, authorization, and safe data handling.
6. Explain how AI is used in web development and applications, critically evaluate its outputs, and recognize its capabilities, limitations, and security implications.
7. Plan, build, test, deploy, and present a complete web application using modern development practices.
