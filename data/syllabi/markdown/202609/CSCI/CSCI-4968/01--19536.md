## Course Description

### Additional Course Description :

This course provides an in-depth exploration of operating system concepts and mechanisms beyond the introductory level. Students will study the design, implementation, and evaluation of modern operating systems, with a focus on advanced topics such as system calls, cpu scheduling, memory management and security, file systems, and device drivers. The course combines theoretical foundations with practical experience, including programming assignments that involve developing and analyzing operating system components. By the end of the course, students will gain a thorough understanding of the principles and challenges in building robust, efficient, and secure operating systems, preparing them for research or careers in systems software development.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Understand Advanced OS Concepts: Demonstrate a deep understanding of key operating system principles, including system calls, cpu scheduling, memory management and security, file systems, and device drivers,
- Analyze System Design: Critically evaluate the design choices and trade-offs made in modern operating systems,
- Implement OS Components: Develop and test operating system modules, applying theoretical knowledge to practical problems,
- Apply Performance Optimization: Analyze and optimize system performance, identifying bottlenecks and improving efficiency in OS operations,
- Address Security and Reliability: Recognize common security threats and reliability challenges in OS design, and propose effective mitigation strategies,
- Communicate Technical Knowledge: Effectively document and present operating system designs, implementations, and analyses.

### Course (Student) Learning Outcomes Assessment Measures:

The measures in this courses include labs, programming assignments, and one on paper exam.

### Additional Academic Integrity Course Policy and Penalty Information:

There will be multiple programming assignments throughout the semester. The programming language we use in this course is C. Written communication skills are assessed in documentation for programming assignments. Documentation is an integral part of projects. Writing is expected to be professional, which includes adhering to grammar, spelling, capitalization, formatting and punctuation standards.

Assignments will be submitted electronically via Submitty. All programs must execute and compile on the **course VM**. Any programming assignment that does not compile and run on the **course VM** will not be graded. Assignments are due on the specified due date. Late submissions will be accepted within 3 days after the deadline with a 10% penalty applied to the earned grade. Submissions more than 3 days late will not be accepted or graded.

Students are allowed to use AI tools (e.g., ChatGPT) for assignments. However, it is mandatory that students fully understand the solutions they submit, and students are responsible for being able to explain, modify, and extend any code or solutions generated with AI assistance.
