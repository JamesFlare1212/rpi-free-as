## Course Description

### Additional Course Description :

Introduction of number systems – decimal, binary and hexadecimal –; variable types including Boolean, integer, float, character and string; general overview of computer architecture and software, programming in “C/C++” including input/output, control statements, operators, functions, arrays, strings, classes, objects, inheritance, pointers, references, file processing, exceptions and operator overloading; brief introduction into MATLAB; design of algorithms for applications that are relevant for biomedical engineering applications.

## Course Goals

### Goals:

This course teaches students:

- Computer architecture
- Algorithms
- Overview of C/C++
- Constants, Variables, Data Types
- Operators and Expressions
- Control Structures, Loops and Arrays
- Modules and Functions
- Pointers and references
- Classes and objects

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- • Demonstrate an understanding of computer hardware and architecture
- • Successfully apply different programming statements, including if, for, while, else, switch.
- • Successfully identify and explain binary and hexadecimal number systems.
- • Show competency to deal with string operations and basic handling of database operations.
- • Solve mathematical problem by translating them into computer codes.
- • Write simple programs to solve BME related problems.

## Grading Criteria

### Criteria Details:

Grading is based on:

- **Quizzes (10%):** There will be between 5 to 7 short quizzes (5 minutes) that cover material discussed on the previous two lectures.
- **Homework Assignments (30%):** There will be a total of 10 homework assignments the include programming tasks, implementation of numerical methods and understanding-type problems and questions.
- **Test 1 (15%):** Based on C programming (fill the gaps, find errors, interpret a given code, write code for a particular problem) on October 10th, 2024, during class time.
- **Test 2 (15%):** Based on C++ programming (fill the gaps, find errors, interpret a given code, write code for a particular problem) on November 25th, 2024, during class time.
- **Final Examination (30%):** Includes similar problems to Tests 1 and 2, related to C/C++ and (fill the gaps, find errors, interpret a given code, write code for a particular problem) for MATLAB. The final examination is during finals week.

## Policies

### Attendance Policy:

As each lecture is offered in-person, attendance is highly recommended. For a successful completion of this course, ***it is essential to review the course material and the codes we develop in class***. ***Lecture material***, except codes that are developed during class, ***will be either posted on LMS with a delay of up to one week or made available before class in the form of handouts***.

### Other Course Policies:

Throughout the course, we will be ***using the online compiler “Replit”***: https://replit.com/~. During the ***first week, create an account*** so that you can participate in practicing coding in class and work on the homework assignments. ***Replit can compile C++*** programs. RPI has MATLAB licenses. For installing MATLAB, follow the instructions on https://itssc.rpi.edu/hc/en-us/articles/360004815472-Matlab-Campus-wide-Install-and-Online-Resources.

**Grading concerns:**

All graded homework submissions and examinations are graded on LMS (feedback will be provided). If there are any questions or concerns, ***there is a one-week window after each homework assignment or test has been graded to seek clarification during the TA office hours. It is important to note that any issue that has not been brought to the attention of the TA one week after an assignment/test was graded is not going to be considered.*** The grades for each homework assignment and the grades for the midterm and final examination will be uploaded on LMS.
