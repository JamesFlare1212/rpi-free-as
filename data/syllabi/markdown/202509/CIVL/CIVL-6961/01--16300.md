## Course Description

### Additional Course Description :

This course introduces the application of machine learning (ML) techniques to solve complex problems in transportation engineering. As urban areas expand and transportation systems become increasingly sophisticated, the need for advanced analytical tools to design, analyze, and improve these systems is more critical than ever. Through a blend of theoretical foundations and practical applications, this course will explore how machine learning can enhance transportation systems' efficiency, safety, and sustainability.

Students will gain hands-on experience with real-world transportation data, machine learning framework, and using machine learning algorithms to tackle challenges such as traffic flow prediction, traffic sensing, public transit optimization, vehicle trajectory analysis, and so forth. The course will cover a range of topics, including but not limited to, python programming, transportation data, machine learning basics, supervised and unsupervised learning, deep learning, and formulating transportation problems properly with machine learning.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Explain the fundamentals of machine learning and its relevance to transportation issues.
- • Apply various machine learning algorithms to analyze and interpret transportation data.
- Design and implement machine learning models to improve transportation systems' performance.
- Evaluate the effectiveness of machine learning solutions in addressing transportation problems.
- Explore other aspects, such as the ethical and societal implications, of deploying machine learning in transportation.

### Course (Student) Learning Outcomes Assessment Measures:

- Homework
  - o Six homework assignments.
  - o Each assignment consists of a Jupyter notebook with coding tasks and short questions.
- Peer Learning
  - o Session 1: Students present a basic machine learning model and a transportation research paper that applies this model.
  - o Session 2: Students present a deep learning model and a transportation research paper that applies this model.
- Paper Implementation Workshop
  - o Students implement a research paper of their choice and present their findings and results in class.
- In-Class Design
  - o Group work in class on a machine learning problem in transportation.
- Final Project
  - o Idea proposal.
  - o Final report.
  - o Final presentation.
- Final Exam
  - o Multiple choice.
  - o Short answers.
- Attendance
