## Course Description

### Additional Course Description :

## Course objective:

This course introduces the methods upon which finite elements are built. Methods covered include the construction of weak forms, the discretization of the weak forms including covering the local/global linkage, construction of element shape functions, element mapping and numerical integration. The course will also cover the application of finite elements methods employing software tools. This will include open-source tools for the efficient implementation of finite elements and commercial software commonly applied in industry.

## Course Text(s)

## Course Content

### Content Details:

## Topics:

- Strong form and weak form of boundary value problem in 1-D (heat conduction)
- Finite element analysis: Galerkin approximation for 1-D Problems
- Finite element method for 2-D Problems (heat conduction and linear elasticity)
- Finite element analysis for time dependent problems (heat conduction)
- Triangular and rectangular isoparametric elements for 2-D problems using Lagrange shape functions
- Numerical integration
- Introduction to other shape function construction methods (p-version and isogeometric)
- Finite element error estimates, derivative (stress) recovery methods
- Introduction to plate finite elements
- Introduction to finite elements for fluid flow problems

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Describe, discuss and explain the fundamental theoretical basis of the finite element method (variational formulation, finite element basis functions, solutions of systems of algebraic equations).
- Demonstrate skill in the application of the method together with existing finite element software for the determination of approximate solutions to meaningful, realistic engineering problems
- Critically examine the results of finite element computations and provide sound, authoritative judgement regarding their validity and reliability.

## Term project (only for MANE/CIVL 6660/6969)

Students taking the course at the graduate level (MANE/CIVL 6660/6969) are required to complete a term project. It should be performed **individually**. Here are some deadlines to follow:

**September 24, 2025:** A **one-page project proposal** should be submitted by September 24th. This should indicate the type of project and a summary of the expected project activities. Please make sure the instructor has approved the project before beginning to work on it.

**November 5, 2025:** A **one to two page only progress report** should be submitted during the middle of the semester. This report should include a concise description of the activities carried out to date and those that remain to be carried out. The report should indicate any questions the student has with respect to the input/help they would like to have to be able to complete the project.

**December 12, 2025:** A **final report** is due at the end of the semester. These reports are expected to be of a high quality in terms of technical content, formatting, and writing. In the past, students have been able to use their reports as a basis for publications. The final report should be comprehensive, self-contained, and MUST include all the details and content from the midterm progress report as well. Detailed instructions regarding the final report will be provided later in the semester.

**Final exams week**: A **presentation** on the project should be given during the final exam week.

All items are due at **11:59 PM (Eastern Time Zone)** on the day they are due.

**Grading Rubric:** Project proposal: 1%, Progress report: 4%, Final Report: 85%, and Presentation: 10%.

Although the weightage for the proposal and progress report is small, it should be noted that their quality and due diligence during submission will directly affect the quality of the final report. Your final report may not be graded if your project proposal and progress report have not been submitted and approved.

The project can be selected from the following two options. Additional details regarding the projects will be provided later.

**Option 1. Solve a PDE in FEniCSx**.

Pick a PDE that you are interested in solving that is time dependent, uses a mixed formulation, or is of a similar level of complexity. One such example is the wave equation in two or three dimensions . You should **NOT** choose a PDE/formulation that has existing FEniCSx tutorials. You must describe the numerical formulation in detail, provide FEniCSx code that runs on the class server, and show verification of your implementation. For example, here are some items that you should include in your report:

1. Derive the weak form of the PDE, describe the function spaces, and matrix equations. For a time dependent problem, develop an implicit and explicit time marching scheme.
2. Prove that the selected PDE is linear (or nonlinear).
3. Comment on the stability and accuracy of the selected method. For a time dependent problem, what will control the critical time step?
4. Show rate of convergence with h and p refinement.
5. For a mixed method, comment on the choice of function spaces. Can you use the same function space for each field? If not, do any combinations work better than others?
6. Make use of a patch test, method of manufactured solutions, and/or other methods to verify FEM solution.

**Option 2. Independent project**.

In most cases these projects will be research oriented and coordinated with the student’s advisor with whom the student determines a plan to execute a project based on finite elements. Common projects include the following, however, you must clearly motivate your choice in the context of your graduate work.

1. Perform a FEM analysis on a novel structure using a commercial or research code. You will be expected to document the numerical methods used by the code and steps needed to construct the analysis. You will also be required to do further analysis of the numerical schemes such as comparing element types, mesh convergence, etc.
2. Perform a literature review on state-of-the-art finite element procedures. The report must review multiple papers and demonstrate that the student gained an understanding of the material in those papers by having the report provide a technical discussion, and comparison (in many cases this means pseudo-code), of the methods presented in the papers reviewed. Typical course literature reviews are on the order of 20 pages and include a properly cited set of papers. Some example topics include:
   1. Phase field methods
   2. Finite element methods for fluids
   3. Multiscale finite element methods
   4. Implementation of finite element methods on GPUs/accelerators
   5. Integration of machine learning and finite element methods
3. Software development. A typical project here would be to add some new capability to an existing finite element simulation workflow under development by a research group. Some examples include:
   1. Add a new material model through an Abaqus UMAT capability.
   2. Adding a new element to MFEM.
   3. Adding a new a posteriori error estimator to an existing finite element code.
   4. Adding a new time marching procedure, or non-linear solver to an existing finite element code.
   5. Employing PCMS to couple two mesh-based simulations as required to solve a multi-physics problem.
