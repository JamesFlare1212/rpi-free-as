## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- • to select simplifying assumptions in analyzing a complex thermo-fluids system.
- • to analyze thermo-fluids systems by applying conservation of energy.
- • to analyze heat transfer in thermo-fluid systems by identifying heat transfer modes–convection (forced/natural, internal/external), conduction (transient and steady-state) and radiation using the appropriate equations to evaluate them.
- • to analyze the performance of heat exchangers and design heat exchangers given a set of specifications.

## Grading Criteria

### Criteria Details:

**Module 1,2,3,and 4:** A grade of 85 and up on each of these four modules will bring your grade up two levels. A grade between 70-84 will bring your grade up one level. A module is considered unsuccessful if its score is less than 70. In this case, no level is earned. Module tests are closed book, but a crib sheet is allowed. The crib sheet must be turned in with the test. **Passing Module 1 is required to pass the class.**

**The grade of each module (1, 2, 3 and 4) is calculated as follows:**

Module grade  
10% Module homework score

20% Module in-class assignment score

70% Module test score

**Class Project**

**This class has a mandatory class project.** In order to pass the class each student must turn in the class project and have a passing grade. Not meeting these requirements results in automatic course failure.

*The project work may start after the completion of Module 2 and the project will be announced during one of the Module 2 lectures.*

**Project grade assignment**

**Two grade modifiers** (i. e., the grade increases by two levels, for example from C to B-) are applied if the project design analysis is correct and it meets the specification (i.e. it is not overdesigned nor underdesigned) and the approach is entirely correct and the project is completed and turned in by November 6th 2025.

**One grade modifier** (i.e., the grade increases by one level, for example from C to C+) is applied if the original design analysis is incorrect/ does not meet specification, but the team addresses the weakness and returns a correct design analysis and a design that meets specification (i.e. it is not overdesigned nor underdesigned) by December 1st, 2025. *If the revised project design and analysis continue to fall short of the design requirements and/or contain partially incorrect results, the student will fail the class.*

**Class organization:** We will meet twice weekly for 110 minutes each time. The class follows a studio format and consists of small segments of lecture time intercalated with in-class exercises/assignments.

**Homework** will be assigned on Wileyplus and will be graded automatically. The homework is due on Wednesdays at 9 PM.

**In-class assignments** will be collected at the end of the class with exception of special accommodation students who will have an alternative collection time.

The use of AI tools, web browsing, or any applications outside the Learning Management System (LMS) during assignments is strictly prohibited. Violation of this policy will result in a grade of zero for the assignment.

***The module tests** are closed book. One page crib sheet will be allowed. The tests are one hour and consist of up to two problems and a few conceptual questions. Test 1 can be retaken 2 times to pass the class or improve grade, while Test 2 can retaken one more time. Test 3 and 4 cannot be retaken. For test schedule please see the table at the end of this syllabus.*

### Attendance Policy:

**Attendance**

Attendance in lectures is not mandatory but is very strongly recommended. Each student is responsible for all materials presented and all announcements made in class.

All missed in-class assignments will receive a zero. However, the lowest in-class assignment grade for each module will be dropped, allowing one absence to be covered. **Students who miss more than one class with a valid excuse can complete similar assignments during a one-hour makeup session supervised by the TA.** One makeup session will be scheduled per module, with the timing based on student availability. If a student misses two or more in-class assignments within a module, all must be completed during the same one-hour session. This will be the only opportunity to make up missed assignments.

Missed tests must be taken during the next available testing window, as indicated in the schedule at the end of the syllabus. If one or more tests are missed and the student cannot complete them during the available windows, a three-hour cumulative exam will be administered during finals week to replace all missing tests.

### Additional Course Information:

**Study Time**

Learning the material will require effort in class and outside of class. The rule-of-thumb for the needed amount of study time for college level classes is approximately *two-three hours outside for each contact hour. Thus, for this 3-credit class, you should set aside up to 12 working hours per week including class time*. Note that some courses require less time; others require more. Likewise, some individuals need more or less time depending on their background, ability, study habits, etc. Several steps can be taken to improve your learning of the material. Studying on a regular basis is more effective than cramming. Reading and/or thinking about the topics to be covered in lecture before attending the lecture can result in better understanding; this approach is particularly effective since new material introduced in lecture then is not so overwhelming.
