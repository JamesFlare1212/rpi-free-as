### Other LMS Information:

UI Art is the art and design field implemented for creating things like inventories, stores, character screens, icons, and other graphics used in the User Interfaces for video games. It is a heavily graphics oriented medium utilizing applications like Photoshop, Illustrator, After Effects, and requiring engine implementation as well. Students will be learning how to use these applications in from the perspective of UI/UX design. Animation, rasterization, vector art, and UI programming will all be implemented.

Students will also analyze and critique existing UI's in video games to better understand contemporary workflows, organizations methodologies, and UX theory. UI's have grown increasingly more complex in the last few years as video games have gotten more and more complicated. The information and feedback required for the player to understand the systems has grown tremendously, thus making the UI's much more difficult to execute effectively. There have been many cases of success in elegantly implementing these UIs and failures, and students will be evaluating both to understand how to give themselves the best chance at success when implementing their designs.

The class comprises partially as a UX class (studying the construction of UI and how users engage with it), but also as a UI Art class (making the elements in use visually appealing/on theme). Students will need to ossicalte between both mindsets to successfully blanace their work as UI Designers.

### Course (Student) Learning Outcomes Assessment Measures:

1. ###### Pastiche - Students will be recreating an existing UI in order to practice their Photoshop and Illustrator skills while analyzing existing successful UI design.
2. ###### Redesign - Students will be analyzing a failed UI in games, and rebuilding it in utilizing their own more successful design theory.
3. ###### Themed Design - Students will be given a set of systems, and a theme and must build a UI mock up that successfully demonstrates those mechanics and the theme.
4. ###### UI Kit - Students will be assembling a kit of UI elements (buttons, sliders, cornering elements, etc.) that can be used for adhoc UI develeopment.
5. ###### Animated Elements - Students will be working on a suite of animated elements like health bars decreasing, scores being added, et.
6. ###### Logo - Students will be creating a marketing package for a game and utilizing basic graphic design and marketing theory.
7. ###### Implementation - Students will need to make their animated elements functional in Unreal.
8. ###### Midterm - Students will be assigned a random static UI element on the day, and will have the class period to rebuild it.
9. ###### Final - Students will be assigned a random animated UI element on the day, and will have the class period to rebuild it and implement it to Unreal Engine 5.
