## Course Description

### Additional Course Description :

This course provides an in-depth exploration of operating system concepts and mechanisms beyond the introductory level. Students will study the design, implementation, and evaluation of modern operating systems, with a focus on advanced topics such as system calls, cpu scheduling, concurrency, synchronization, memory management, file systems, virtual memory, and device drivers. The course combines theoretical foundations with practical experience, including programming assignments that involve developing and analyzing operating system components. By the end of the course, students will gain a thorough understanding of the principles and challenges in building robust, efficient, and secure operating systems, preparing them for research or careers in systems software development.

## Course Goals

### Goals:

By the end of this course, students will be able to:

1. **Understand Advanced OS Concepts:** Demonstrate a deep understanding of key operating system principles, including system calls, cpu scheduling, concurrency, synchronization, memory management, file systems, and device drivers.
2. **Analyze System Design:** Critically evaluate the design choices and trade-offs made in modern operating systems.
3. **Implement OS Components:** Develop and test operating system modules or simulations, applying theoretical knowledge to practical problems.
4. **Apply Performance Optimization:** Analyze and optimize system performance, identifying bottlenecks and improving efficiency in OS operations.
5. **Address Security and Reliability:** Recognize common security threats and reliability challenges in OS design, and propose effective mitigation strategies.
6. **Communicate Technical Knowledge:** Effectively document and present operating system designs, implementations, and analyses.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Explain and analyze advanced operating system concepts, including concurrency, process synchronization, memory and storage management, file systems, and security.
- Design and implement components of an operating system or OS simulations to solve complex system-level problems.
- Evaluate and optimize operating system performance through profiling, benchmarking, and resource management techniques.
- Identify and address security and reliability challenges in operating system design.
- Critically assess and compare the design of different modern operating systems.

### Course (Student) Learning Outcomes Assessment Measures:

Programming assignments, mid-term exam, and the final exam.

### Other Course Policies:

Programming Assignments  
There will be 10 programming assignments throughout the semester. Written communication skills  
are assessed in documentation for programming assignments. Documentation is an integral part  
of projects. Writing is expected to be professional, which includes adhering to grammar, spelling,  
capitalization, formatting and punctuation standards.  
Assignments will be submitted electronically via Submitty. All programs must execute and compile  
on the provided virtual machine. Any programming assignment that does not compile and run on  
the provided virtual machines will not be graded. Assignments are due on the specified due date.  
Late submissions will be accepted within 3 days after the deadline with a 10% penalty applied to  
the earned grade. Submissions more than 3 days late will not be accepted or graded.  
Use of AI in Assignments  
Students are allowed to use AI tools (e.g., ChatGPT) for assignments. However, it is mandatory  
that students fully understand the solutions they submit, as exams will primarily be based on and  
focus on the assignments. Students are responsible for being able to explain, modify, and extend  
any code or solutions generated with AI assistance.
