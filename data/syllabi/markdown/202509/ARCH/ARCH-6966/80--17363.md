## Course Description

### Additional Course Description :

This course provides students with a comprehensive introduction to professional applications of Building Information Modeling (BIM) using Autodesk Revit and related cloud and desktop software. The course covers the theory, practice and application of BIM authoring, reporting and collaboration methodologies used in professional architectural, engineering and construction workflows. Students will work in teams to develop a documentation set of an on campus building, develop drawings, extract schedules, perform coordination and quality checking activities. Student team developed models will become part of an online campus database of BIM assets. Course lectures and modeling work will be supplemented with guest lectures from building practitioners and technology development who will discuss the applications of BIM to their organizations.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Demonstrate proficiency in BIM software functionality through weekly homework and in class assignments.
-  Demonstrate ability to develop BIM model of existing building from 2D as built drawings, photographs and point clouds.
-  Demonstrate capability to apply knowledge of BIM concepts including 3D to 2D drawing extraction, parametric modeling, model organization, and data import from CAD and 3D modeling applications.

### Course (Student) Learning Outcomes Assessment Measures:

The course includes weekly assignments and a final project.  
The weekly assignments are used both to reinforce the learning conducted during class, and also build up to develop the overall class project.
