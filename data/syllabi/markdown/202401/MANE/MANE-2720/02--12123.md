## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- LO_1 The student is able to define and explain different methods of analysis used in the field of fluid mechanics.
- LO_2 The student is able to define and explain the difference between laminar and turbulent flow.
- LO_3 The student is able to define and explain important dimensionless parameters in fluid mechanics such as the Reynolds, Euler, and Froude numbers.
- LO_4 The student is able to differentiate between integral and differential methods of analysis and solve fluid flow problems using an appropriate method.
- LO_5 The student is able to translate word problems into mathematical algorithms that may be solved for engineering design parameters.
