## Course Description

### Additional Course Description :

Transforming data into useful information and actionable insights for decision-making is an important skill that is becoming indispensable for scientists and engineers. The objective of this course is to introduce data analytics tools to engineers through hands-on computational applications. Topics include probability and statistics review, data visualization, linear regression, time-series analysis, forecasting, optimization, simulation, and spreadsheet models. Applications will be in Python, MATLAB, and Excel.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Apply data cleaning methods (exploring missing values, duplicates, outliers, etc.)
- Compute descriptive statistics of a given data set
- Analyze and model data using predictive and prescriptive techniques such as linear regression, time-series analysis, forecasting, optimization, and simulation
- Use computational tools for implementing data analytics methods (in Python, MATLAB, and Excel)
- Communicate inferences from data to guide decision-making effectively through text and visualizations considering various audiences including researchers and industry practitioners
- Additional Course Learning Outcome for ISYE6370: Independently conduct a literature review on the applications of selected predictive and prescriptive techniques discussed
- Additional Course Learning Outcome for ISYE6370: Discuss the implications, challenges, and limitations of the frequently used data analytics methods
- Additional Course Learning Outcome for ISYE6370: Present the literature review and data analysis results in professional written and oral formats

### Course (Student) Learning Outcomes Assessment Measures:

Student's Learning Outcomes will be measured through Lab Assignments, Class Participation Exercises, Exams, and Project.

All requests must be made in writing by attaching a well-phrased note to the original work explaining in full the reason for the request and the points you think you deserve for your error. Requests for a regrade must be submitted no later than the next class meeting after the grade is announced or the material is handed back to the class for the request to be considered.

**Special Testing Accommodations:** If you have a special accommodation letter, make sure to email it within the first three weeks of the semester so that necessary arrangements can be made.
