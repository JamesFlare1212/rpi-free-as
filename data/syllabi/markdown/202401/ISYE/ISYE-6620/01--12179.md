## Course Description

### Additional Course Description :

This course covers discrete-event simulation (DES) principles, techniques, and applications. DES uses computer software to model complex real-world systems. Topics include random number generation, queuing theory, input/output analysis, verification and validation and statistical analysis. Hands-on practice with FlexSim, Excel, and Python is included. Upon completion, students can create complex models and manage simulation projects.

## Course Text(s)

### Text Details:

• Course Textbook: Banks, J., Carson II, J.S., Nelson, B.L., and Nicol, D.M., Discrete-Event System Simulation, 5th Edition, Prentice-Hall, 2010.  
• Other References: Law, A.M., Simulation Modeling and Analysis, 5th Edition, McGraw-Hill, 2015.

## Course Goals

### Goals:

To develop complex healthcare and manufacturing simulation models, design the simulation experiment to be run on the model, and analyze and interpret the results, and the management of simulation projects.

## Course Content

### Content Details:

- Basics of Simulation Modeling
- Random-Number Generators
- Generating Random Variates
- Monte Carlo Simulation
- Queuing Theory and Queuing Networks
- Manufacturing Simulation in FlexSim
- Input Modeling
- Healthcare Simulation in FlexSim
- Output Data Analysis
- Verification and Validation
- Multi-Criteria Decision Making (TOPSIS) and DOE
