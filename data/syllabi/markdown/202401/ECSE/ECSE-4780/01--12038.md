## Course Description

### Additional Course Description :

This course aims at preparing students with understandings and hand-on experiences for modern microprocessor design. Students will learn topics in advanced computer architecture and principles for future computer designs. The course is organized by three building blocks in modern computing systems: processors, memory systems, and interconnects, and one module on hardware accelerators. Students will practice prototyping design elements in large-scale digital systems such as general-purpose computing and domain-specific architectures for AI/ML at register-transfer level. Students cannot receive credit for both ECSE 4780 and ECSE 6700.

## Course Goals

### Goals:

With completion of this course, students should be able to:

- Articulate concepts and mechanisms in architecture design of modern microprocessors, memory systems, and interconnects.
- Evaluate the trade-offs of modern computer architecture designs from both qualitative and quantitative analysis.
- Apply understanding of computer architecture in solving problems of modern computing platforms.
- Manage the complexity of implementing and verifying designs of computer systems at the register-transfer level (RTL) using hardware-description language (HDL).
- Equip with the skill set for innovative designs in the future.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Understand the fundamentals of digital design
- Comprehend the basic principles of modern computer architecture
- Learn how modern microprocessors work from bottom up
- Apply the design principles in the implementation of a simple microprocessor
- Test and debug the design systematically
- Manage the design complexity of microprocessors

### Course (Student) Learning Outcomes Assessment Measures:

- There are no exams. Grading is based solely on project preparation, class participation, and project reports.
- All labs are individual assignments. You must write your own code and report. All work is to represent the individual’s independent work and capability, though group discussion on the design hints and debug methods is encouraged. No discussions on code, i.e., HDL, are allowed.
- Discussions on any unusual problems that arose and how they were solved are always welcomed. Reports are graded both on content and presentation (i.e., quality of written content and writing style).
- There is no homework or exam in the course. However, there are many activities that may or should be done outside of the lectures and labs, such as writing HDL code, building circuit schematics, simulations, and debugging.

The gradable materials of all projects involve a detailed report documenting what has been accomplished.

- Design details include I/O and state machine descriptions where appropriate, as well as explanations on how testing was done to verify that the design satisfied the specifications given in the lab.
- Use block diagrams, schematics, timing diagrams, oscilloscope traces, screen grabs, photos, or anything else to document the results. Include an analysis, discussion, and/or conclusion on both technical aspects and overall impressions.
- All project reports are due by Thursday 11:59 PM on the designated deadline.

Report submission policy:

- FIVE late days that can be used towards any projects but not the final project.
- Final project reports are due on the last instruction day; strict deadline, late submissions are not allowed.

Final grades will be curved so that around 20% of the class will receive A, 25% of the class will receive A-, and 50% of the class will receive B+/B/B-.

Class attendance and class participation are not graded. However, at the end of the semester, if a student is on a borderline between grades, these factors will be considered when deciding the final grade.

If you feel a mistake has been made in grading your project reports, resubmit the report within two class sessions of the time the report was returned to you. Otherwise, NO re-grading will be performed.
