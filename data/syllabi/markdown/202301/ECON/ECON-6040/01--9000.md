## Course Description

### Additional Course Description :

This course is designed to help students build a solid ground in data analytics and policy evaluation. Particular attention is given to the analysis of ‘panel’ or ‘longitudinal’ data sets. Topics to be studied include fixed effects and random effects models and their estimation and inference in the linear panel data framework. With a range of applications from the literature, we will also discuss some recently developed econometric techniques for policy evaluation. In particular, quantile regression will be introduced to investigate the heterogeneous treatment effects. Some other recent advances in data analytics including LASSO and adaptive LASSO will be briefly introduced.

## Course Content

### Content Details:

1. Introduction to Panel Data
2. Fixed Effects Models
3. Random Effects Models
4. Dynamic Panel Data Models
5. Test of Hypothesis with Panel Data
6. Quantile Regression and Its Applications
7. Shrinkage Methods with Many Regressors
8. Statistical Inference Using the Bootstrap

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Identify and summarize the important features of panel data models;
- Apply modern econometric techniques to analyze panel data and conduct policy evaluation;
- Demonstrate knowledge about the significance of current developments in panel data analysis by writing an applied research paper;
- Gain competence in the statistical software R.
