### Additional Information for Course Information Section:

The primary objective of the course is to provide an introduction to the theory and application of model predictive control (MPC). Model predictive control is the class of advanced control techniques most widely applied in the process industries. A primary advantage to the approach is the explicit handling of constraints. In addition, the formulation for multivariable systems with time-delays is straightforward.

MPC was developed in the process industries in the 1960’s and 1970’s, based primarily on heuristic ideas and input-output step and impulse response models. The basic principle is to solve an open-loop optimal control problem at each time step. The decision variables are a set of current and future manipulated variable moves and the objective function is to minimize deviations from a desired trajectory; constraints on manipulated, state and output variables are naturally handled in this formulation. Feedback is handled by providing a model update at each time step, and performing the optimization again.

Since students with a variety of backgrounds will be taking this course, we first provide a review of continuous process models and regulation using continuous and discrete PID controllers; we then show how to implement these controllers in MATLAB. The discrete internal model control (IMC) approach is presented as a low-order, model-based control strategy, and placed in the context of “classical” digital algorithms, such as *deadbeat* and *Dahlin’s method*. A historical perspective of various MPC approaches follows. We then derive the analytical solution for the unconstrained problem. The quadratic programming solution for linear models and constraints and a quadratic objective function is presented.

Recent results on stability, robustness and state estimation will be covered. Alternative formulations that are used by major MPC vendors in industrial applications will be presented. Extensions to nonlinear systems using different types of nonlinear models will be studied. MATLAB will be used for the simulation of MPC applied to different problems. In addition to homework assignments students will complete a major research/design project.

Usually, the course is taught in a *studio format*, combining lectures and simulations. This semester it is being taught largely through lecture screencasts and the tutorial use of MATLAB Livescripts. On-line quizzes will often be due before class time, to assure that all students have reviewed the material.

Students will often modify the MATLAB script files for their homework solutions. It is assumed that all students have taken an undergraduate control course, with content similar to that of Bequette (2003). This text will be used for a review of basic modeling concepts and an introduction to MPC. Copies of relevant literature sources and teaching materials will be provided throughout the course. Graduate students will be expected to perform more detailed analysis in homework problems as well as the course project.

## Course Goals

### Goals:

Given a digital control algorithm, such as PID or IMC, and a plant model (set of ordinary differential equations) students should write MATLAB code to simulate the closed-loop behavior.

Students should understand and be able to demonstrate the difference in closed-loop behavior of deadbeat, Dahlin’s and digital IMC, applied to a given linear process model.

Students should demonstrate an understanding of the basic concept of state controllability by being able to generate a sequence of inputs to bring a system from an initial state to a desired final state, using MATLAB to solve the problem.

Students should be able to derive and simulate a basic “coincidence point control” strategy, where a sequent of manipulated inputs is applied to achieve a desired output at the end of a future “prediction horizon.”

Students should be able to implement dynamic matrix control (DMC) by solving a given problem using MATLAB. They should demonstrate the effect of prediction horizon and control horizon using simulation examples.

## Course Content

### Content Details:

**Topics**

Using MATLAB to integrate initial value ordinary differential equations (ODEs)

Using MATLAB to discretize continuous-time systems

Implementing discrete-time controllers on continuous-time plants, using MATLAB

Discrete internal model control (IMC) and relationship to deadbeat and Dahlin’s controllers

Dynamic Matrix Control (DMC)

Quadratic Dynamic Matrix Control (QDMC)

State space model-based predictive control, including formulations for constraints

State estimation techniques

State estimation-based MPC

Nonlinear model predictive control
