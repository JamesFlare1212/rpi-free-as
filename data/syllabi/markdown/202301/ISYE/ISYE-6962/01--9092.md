## Course Description

### Additional Course Description :

Transforming data into useful information and actionable insights for decision-making is an important skill that is becoming indispensable for scientists and engineers. The objective of this course is to introduce data analytics tools to engineers through hands-on computational applications. Topics include probability and statistics review, data visualization, linear regression, time-series analysis, forecasting, optimization, simulation, and spreadsheet models. Applications will be in Python, MATLAB, and Excel.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Apply data cleaning methods (exploring missing values, duplicates, outliers, etc.)
- Compute descriptive statistics of a given data set
- Visualize data using suitable charts
- Analyze and model data using predictive and prescriptive techniques such as linear regression, time-series analysis, forecasting, optimization, and simulation
- Formulate engineering problems as optimization models
- Use computational tools for implementing data analytics methods (in Python, MATLAB, and Excel)
- Draw reliable inferences from data to guide decision-making
- Communicate findings of data analytics effectively through text and visualizations considering various audiences including researchers and industry practitioners

### Course (Student) Learning Outcomes Assessment Measures:

Student's Learning Outcomes will be measured through Lab Assignments, Class Participation Exercises, Exams, and Project.

## Grading Criteria

### Criteria Details:

The final grade in the course is based on the following items:

- **Exams (2 Exams × 25 points = 50 points):** Students will have two exams within the semester.
- **Labs and Class Participation Exercises (CPE) (30 points):**
  - o **Labs (4 Labs × 5 points = 20 points):** Lab work includes solutions to assigned problems to be uploaded in required file formats in LMS before the specified deadlines.
  - o **Class Participation Exercises (CPE) (10 CPEs × 1 point = 10 points):** Each student should provide their response to CPEs through LMS. At the end of the semester, three of the lowest CPE grades will be dropped, including missing CPEs with or without an excuse. If, for some extraordinary reason, you have more than three absences, you will be graded over the remaining CPEs.
- **Final Project (20 points):** To be developed towards the end of the course, including presentations the last week of class. The project can be completed by a team of at most two students.

The total points earned in the course will be the weighted sum of points on the assessment requirements. Point totals will be rounded up for assigning the final grade. The final course grade will be assigned using the ranges below. Final grades will not be changed unless a numerical error is made in computing your final grade. ## Policies

### Other Course Policies:

**Missing Exams or Assignments:** Missing exams are only allowed if there is an emergency verified by the Dean of Student’s office. There are no makeups for exams. Missing assessments without official excuses will receive a zero.  
**Excusal from Course Exams or Assignments:** If you know ahead of time that you will miss an exam or an assignment deadline, then you must make arrangements before the assessment is due. Failure to do so will result in 25% off for each 24-hour period the assessment is late.  
**Exam Protocol:** The use of calculator and reference sheets is allowed in the exams. All answers must be recorded on the exam answer sheet and full credit is awarded for correct numerical answers as well as direct answer to the problem presented in the question. Little or no credit is awarded for effort that yields incorrect numerical values since the professional world measures performance on correct results.  
**Exam Regrading Request:** Exams submitted for regrading must not be altered from the original work submitted for grading. Altering work for regrading is academic dishonesty and will be treated as such. All requests must be made in writing by attaching a well-phrased note to the original work explaining in full the reason for the request and the points you think you deserve for your error. Requests for a regrade must be submitted no later than the next class meeting after the grade is announced or the material is handed back to the class for the request to be considered.  
**Special Testing Accommodations:** If you have a special accommodation letter, make sure to email it within the first three weeks of the semester so that necessary arrangements can be made.
