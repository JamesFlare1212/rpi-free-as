## Course Description

### Additional Course Description :

This is an introductory course in Biology. It is intended for undergraduates, both non-majors and majors. It serves as the first course for life science majors and for students interested in the health professions.

Laboratory activities include scientific computing in interactive virtual environments using Python & R for data processing, analysis, and visualization. Students generate hypotheses via simulations, and share their ideas in interactive in-person mini-groups. Hands-on wet labs impart basic cell and molecular biological skills.

The goal is for students to gain biological literacy by applying the scientific method. Students will use quantitative tools, develop data dexterity, and analytical thinking skills and learn basic laboratory skills. This is a D1 Data Intensive Course.

## Course Content

### Content Details:

#### The Scientific Method is applied to understand fundamental concepts in:

- Cell Biology - Mitosis, Meiosis, and the Cell Cycle.
- Molecular Biology - DNA replication, Protein Synthesis, and Regulation.
- Microbiology - Prokaryotic (versus Eukaryotic) cell size, shape & morphology.
- Virology - SarsCov2 genome & spike protein data visualization using PDB.
- Biochemistry - Structures of amino acids, nucleotides, atoms and bonds using an Artificial Intelligence Learning Platform.
- MolBio Techniques/Skills - Wet Lab extraction of DNA from plant/animal samples collected via RPI campus Field Trip, Gel electrophoresis & PCR preparation.
- Medicine - Drug/vaccine design and genetic engineering using Simbio’s simulations.
- Genetics - Mendelian Patterns, probabilities, ratios, Chi Square Analysis using corn purple/yellow plump/wrinkled mutant kernels or Fruit Flies.
- Ecology, Biodiversity and Conservation - Ecosystems, Biodiversity, Conservation, Epidemiology, eg., R0, vaccine critical threshold, Hardy Weinberg Allele frequency and other calculations, R Scripting.
- Evolution, Phylogeny - Cladistics, Bioinformatics, and basic Computational Data Analytics using Python scripting.
