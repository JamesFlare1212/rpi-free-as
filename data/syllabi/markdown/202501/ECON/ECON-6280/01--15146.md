## Course Description

### Additional Course Description :

This course goes far beyond the classical statistical methods, such as linear regression, that are introduced in ECON4570/6560 (Econometrics/Introduction to Econometrics). It aims to provide an overview to such modern non-linear methods as Generalized Additive Models, Decision Trees, Boosting, Bagging and Support Vector Machines as well as more classical linear approaches such as Logistic Regression, Linear Discriminant Analysis, K-Means Clustering and Nearest Neighbors. This course will cover all of these approaches in the context of Marketing, Finance and other important business decisions. At the end of this course you should have a basic understanding of how all of these methods work and be able to apply them in real business situations. With the explosion of Big Data problems, statistical learning has become a very hot field in many scientific areas as well as marketing, finance and other business disciplines.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- develop and implement statistical learning algorithms. apply and evaluate statistical learning algorithms on real data sets.

### Course (Student) Learning Outcomes Assessment Measures:

In line with the applied nature of this class, a large portion of the assessment will be made through homework. There will be approximately four homework assignments. The homework will contain some theory questions but the majority of the material will involve implementing the different methods that we cover in class using the computer package. There will also be an empirical project and there will no final exam.
