## Course Description

### Additional Course Description :

This is an undergraduate course which provides an introduction to the various computational tools and environments that physicists use on a daily basis in the course of their research. Students should develop the computational tools necessary to investigate physical problems (data handling/fitting, solving systems of equations, ordinary and partial differential equations) both analytically and numerically. Further, they will develop fundamental tools for performing research in physics, e.g., data visualization, producing publication quality figures, and familiarity with scientific paper text editors (LateX).

## Course Content

### Content Details:

Linux environment, command line (bash), basic scripting  
Data file handling, fitting, manipulation and visualization  
Generation of publication quality scientific figures  
Jupyter-notebook and scientific Python libraries (e.g., numPy, sciPy, etc)  
Solving problems analytically using Mathematica  
Random numbers, Stochastic processes  
Root finding, numeric integration/derivative  
Writing program to solve ODEs  
Solving systems of linear equations using Matrix solvers.

### Course (Student) Learning Outcomes Assessment Measures:

The course consists of two regular class meetings per week. In class meetings will consist of lecture portion and an in-class activity. There will be frequent short homework assignments designed for students to practice and reinforce techniques learned in lecture. Each homework assignment will be posted on the RPI LMS website. Homework will be due at 11:59pm on their due date and completed homework should be uploaded to the LMS as a pdf file. Homework will typically be assigned the day after the previous homework is due. In addition to a cumulative final, there will be three exams in this class where students will be expected to perform computational tasks in the allotted time. At the end of the examination, the students will upload their work to the LMS.
