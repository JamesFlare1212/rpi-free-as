## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Evaluate the opportunity for using data in combination with machine learning and artificial intelligence to add value across a broad range of use cases
- Develop machine learning solutions for data-driven problem solving
- Calculate the accuracy of machine-generated predictions and classifications
- Evaluate the competitive and strategic position of the organization with respect to the use of data
- Recommend specific strategies to improve the organization’s performance using data
- Propose strategies for new opportunities, products and services using data and machine learning strategies to fulfill a market or corporate need.
- Evaluate data, machine learning products and solutions that may have potential for driving new value to their organizations
- Articulate how specific initiatives of the organization using data with machine learning or machine intelligence techniques may influence financial and strategic performance
