## Course Description

### Additional Course Description :

In this course we will use the Unity Game Engine along with other tools to explore and develop:

Multi-user systems using either shared and/or networked user interfaces

Multi-Modal applications that provide an enhanced sense of immersion using pseudo-3D systems.

Analyze, critique and create interactive data visualizations and simulation.

Students will apply knowledge gained and techniques learned in fundamental classes to develop new visualization, simulation and game demos to develop experience and understanding of visualization techniques using Game Engine technology along with other user experience design and data analytics and web tools.

## Course Text(s)

### Text Details:

recommended - "Envisioning Information" by Edward Tufte and "Information Visualization, Perception for Design" by Colin Ware

## Course Goals

### Goals:

The intention is to provide as close to a real world development and use case of visualization and simulation in a technically immersive setting. We will be using "The Campfire" as one target platform, but will also form an appreciation for other immersive platforms such as VR/AR headsets and large scale immersive "Cave" settings (like the CISL/EMPAC 360 screen)

## Course Content

### Content Details:

Data Visualization  
Collaborative discovery and sensemaking using Immersive Technologies  
Physical Simulations as both literal simulations as well as in modeling the behaviour of other abstract phenomena (data analytics, etc.)

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Develop Collaborative Applications using the Unity Game Engine
- Demonstrate the Design and Implementation of basic realtime simulations using a Game Engine
- Work with collected data to model, simulate and analyze a system

### Course (Student) Learning Outcomes Assessment Measures:

Students are expected to participate in class discussions, demonstrations and exercises (labs)  
Students will present and defend research findings and proposed solutions in class  
Students will develop individual and group projects and be assessed based on the ability to demonstrate mastery of the class materials and learning outcomes.

### Additional Academic Integrity Course Policy and Penalty Information:

The following are examples of acceptable behavior:

- Whiteboarding solutions with others using diagrams or pseudocode
- Using the web or other external resources for additional instruction, references, or solutions to technical difficulties
- Incorporating snippets of code (up to about 2 lines) that you find online into your own code, provided those snippets are not themselves solutions to assigned problems and that you cite their origins
- Running someone else’s code on your computer to see how their game works

The following are examples of UNACCEPTABLE behavior:

- Asking to see a classmate’s solution to a problem before submitting your own
- Showing a classmate your solution to a problem before they submit their own
- Whiteboarding solutions with others using actual code
- Searching for outright solutions to projects or problems online or elsewhere
- Splitting a problem’s workload with another individual and combining your work
- Submitting the same or similar work as that for another class
