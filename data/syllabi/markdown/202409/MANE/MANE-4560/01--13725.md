## Course Description

### Additional Course Description :

The objective of this course is to present an introduction to robotic arms (manipulators). This includes kinematics, dynamics, and control. Homework and exams will be used to demonstrate an analytical understanding of basic principles necessary for robotic system analysis and utilization. A group project will be used to demonstrate a practical application of these principles.

## Course Content

### Content Details:

- Definition, properties, and manipulation of vectors and matrices
- 2D and 3D rotations and translations
- Coordinate transforms
- Workspace and arm definitions
- Forward kinematics
- Inverse kinematics
- Differential kinematics
- Jacobian definition, computation, and singularity analysis
- Path generation
- Trajectory generation
- Basic feedback control
- Camera modeling and calibration
- Visual servoing
- Rigid body dynamics

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Ability to describe a robotic arm in terms of joint types, rotation and translation axes, and link lengths
- Ability to determine the end effector pose given the arm description and joint angles (forward kinematics)
- Ability to find joint angles that would result in an end effector pose given the arm description (inverse kinematics)
- Ability to define the manipulator Jacobian and identify its singularities
- Ability to generate end effector and joint angle paths and trajectories
- Ability to implement basic feedback control to imporve trajectory tracking
- Demonstrate application of course theory on hardware
- Implement theory for a topic outside course scope on hardware
- Understand the parameters of the standard manipulator dynamic equations
