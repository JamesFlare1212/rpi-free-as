## Course Description

### Additional Course Description :

Design Programming 1 provides an accelerated introduction to computer programming for design professionals including instruction in 2D and 3D graphics, Web applications, and building data. The course provides an accelerated introduction to prevalent programming languages and constructs, graphics libraries and development environments. The course spans from an introduction to the basic concepts of general programming, object oriented programming and 2D graphics through basic web design, 3D graphics on the web building data modeling and web database integration. This class is oriented to students who are interested in going beyond simply using 2D and 3D programs, who want to better understand the technologies behind these tools, and access capabilities beyond those of simple scripting. Students develop a web based design modeling application targeting their domain of design interest over the course of the semester, as well as learning technical skills through weekly exercises.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Demonstrate comprehension of foundational programming concepts including coding languages, data types, conditionals and loops, and their practical applications in languages including Java and JavaScript.
- Demonstrate comprehension of 2D and 3D programming concepts including geometric primitives, geometric transformations, and coordinate geometry.
- Demonstrate ability to generate, modify and debug AI generated code for use in the student’s software development project.
- Demonstrate comprehension of interactive, web based programming including event based programming, web documents, and client server interactions.

### Course (Student) Learning Outcomes Assessment Measures:

The course includes weekly assignments and a final project.  
The weekly assignments are used both to reinforce the learning conducted during class, and also build up to develop the overall class project.

## Grading Criteria

### Criteria Details:

Percentage of grade determined by each part of the course sequence:

- Participation[1] 20%
- Assignments 40%
- Final Project 40%

At the eighth week of the semester, students will receive notification if their grade for the semester is in danger of being below a C or below. Written appeal may be made to the instructor for each assignment, mid term notification, and final grade. If this appeal to the instructor doesn't satisfactorily resolve the matter, the appeal will be referred to the Associate Dean for Undergraduate Studies in the School of Architecture.

Attendance:

Attendance is required for all course meetings during the semester. Three unexcused absences will result in the lowering of your grade by one letter. Six unexcused absences from studio during the term result in an automatic F.
