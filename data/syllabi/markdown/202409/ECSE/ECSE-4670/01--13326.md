## Course Description

### Additional Course Description :

Introduction to the basic concepts of computer and communication networks, like flow control, congestion control, end-to-end reliability, routing, framing, error-recovery, multiple access and statistical multiplexing. In-depth presentation of the different networking layers, with emphasis on the Internet reference model. Protocols and architectures such as the TCP, IP, Ethernet, wireless networks etc. are described in order to illustrate important networking concepts. Brief introduction to quantitative analysis and modeling of networks.

## Course Content

### Content Details:

**Specific topics** to be covered in this course:  
• Introduction to layered architectures and protocols  
• Packet delay types and delay analysis using space-time diagrams  
• Application layer protocols: HTTP, FTP, SMTP and DNS  
• Principles of reliable data transfer  
• Internet transport protocols - TCP and UDP  
• IP addressing  
• Routing algorithms: link-state and distance-vector  
• Internet routing protocols: RIP, OSPF and BGP  
• Queuing delay and occupancy analysis for packet networks  
• Packet error detection and correction  
• Multi-access mechanisms: Aloha and CSMA/CD  
• Ethernet link layer technology and LANs  
• Analysis of Wireshark packet traces  
• Socket programming using UDP

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Understand how space-time diagrams can be used to calculate end-to-end packet delays in a communication network.
- Understand how different application layer protocols like HTTP, FTP, SMTP and DNS work.
- Understand the principles of reliable transfer of data and congestion control and how these functions are implemented in transport layer protocols like TCP and UDP.
- Understand addressing conventions and routing algorithms used in the Internet.
- Understand fundamentals of queuing theory, and how they can be used in analyzing average delay and buffer requirements at routers.
- Understand basic multi-access communication protocols, and their implementations in link layer standards/technologies like Ethernet and WiFi.
- Analyze Wireshark traces to understand how and application and transport layer protocols work.
- Building an application over UDP using socket programming.
