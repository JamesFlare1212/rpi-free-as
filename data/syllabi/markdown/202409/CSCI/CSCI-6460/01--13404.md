## Course Description

### Additional Course Description :

- This course focuses on software development techniques in supportof large-scale software projects and maintenance
- Specific topics include various programming paradigms and techniques,approaches to testing and automation, debugging, refactoring, and inheriting code
- Individual and team assignments are required, including programming assignments
- Project topics include text processing, building a search engine, and the like
- This is a communication-intensive course

For undergraduate students, this course servesas a CSCI in-major communication intensive (CI)course  
Therefore, expect a lot of writing (not just code!),a lot of communication with your classmates, andboth individual and team presentations  
Communication with your classmates will entailboth a semester-long team project and smallerin-class mini-projects and assignments  
We will also have class discussions in which participation is important!  
For students registered for CSCI 6460, you will have the same assignments as those given for CSCI 4640, with additional questions on some assignments  
You will also take on a more “senior” or leadership role withinyour project teams; therefore, some team assignments willhave additional questions and responsibilities

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Efficiently identify defects in software systems, in particular in functions,\&nbsp;modules, classes, interfaces, designs, code, etc.
- Demonstrate the ability to scale up, i.e., to refactor and effectively maintain\&nbsp;increasingly large-scale code bases
- Design and implement repeatable test plans that ensure high levels of quality
- Identify (and avoid) anti-patterns in software design, development, and testing
- Effectively coordinate a software development teams to facilitate successful communication, organization, and progress toward demonstrable goals
