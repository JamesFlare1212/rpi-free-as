## Course Description

### Additional Course Description :

An intermediate level games writing course, building off the core principles and introductory elements of Introduction to Game Storytelling. This course delves deeper into the working practices of games writers, exploring adaptation, in-game dialogue, character creation, story beats, game industry writing tests, and writing software.

The class is largely project-based, with a high level of class participation with student presentations. Student projects and skills acquired culminate in a voice recording session, which students will direct, from their own script in line with a brief.

## Course Goals

### Goals:

The course is designed to provoke analytical consideration of narrative elements in games, and to expose students to the practice of creating narrative elements within a framework of guidance and industry experience.

**ASSIGNMENTS LIST**

- \- A brief presentation demonstrating how the set brief has been addressed to turn a property from some other form of media into a game.

- \- A brief presentation demonstrating how the set brief has been addressed to write some on-tone, in-character dialogue for a game of the student’s choosing.

- \- A presentation to demonstrate a grasp of how story beats and beat sheets function as a means to create well-structured stories.

- \- Write a screenplay as part of an industry test to demonstrate your understanding of how screenplays should look, and why.

- \- Create a game in Twine as part of an industry test to demonstrate your understanding of how to use this software.
