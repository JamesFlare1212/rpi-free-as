## Course Description

### Additional Course Description :

The course covers topics related to matrix algebra and matrix decompositions, including eigenvalue and generalized eigenvalue problems, solving multivariate constraint and unconstraint optimization problems, gradient-based optimization for solving nonlinear optimization problems, and regression analysis. Important concepts that are discussed include Karush-Kuhn-Tucker conditions for solving nonlinear optimization problems, first- and second-order gradient-based methods, parameter estimation methods including data-driven multiple linear regression and determining unknown parameters of mechanistic models. The course also provides a discussion of important data science tasks of data analysis, regression, classification and presents application studies related to biomedical engineering.

## Course Goals

### Goals:

This course teaches students how to:

- Understand the need for numerical methods to solve biomedical engineering problems.
- Comprehend the use of matrix decompositions for computing numerical solutions.
- Apply traditional methods to determine the optimum of an objective function.
- Utilize first- and second-order gradient-based optimization methods to solve nonlinear optimization problems.
- Distinguish between the various data science-related tasks.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Using matrix decompositions to condition the solution of complex and large-scale algebraic equations and increase the accuracy of the solution.
- Solving large-scale multivariate nonlinear optimization problems by using gradient-based optimization methods.
- Setting up data-driven problems and estimate unknown model parameters.

### Course (Student) Learning Outcomes Assessment Measures:

**Homework Assignments:** There will be a total of 3 homework assignments, which contain understanding type problems based on the methods covered in class. Homework 1 covers material discussed during the first three weeks and homework 2 is based on the material presented during the week four to seven. Homework 3 covers topics covered in week nine to twelve.

**Midterm Examinations:** There is one midterm examination. It covers the lectures one to seven on fundamentals of numerical linear algebra as outlined in the course calendar. Midterm examination is scheduled during class for a duration of 80 minutes. Midterm exams contain understanding type questions about the methods and solving related problems.

**Final Examination:** There is one final examination that comprehensively assesses the course material. The exam will include understanding type questions about the methods covered in this course and also present plots of modeling results that are to be interpreted. The final exam is during final’s week.

**Project:** The course includes one project to apply the methods discussed in class on problems in biomedical engineering.
