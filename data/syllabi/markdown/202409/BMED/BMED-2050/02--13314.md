## Course Description

### Additional Course Description :

Introduction of number systems – decimal, binary and hexadecimal –; variable types including Boolean, integer, float, character and string; general overview of computer architecture and software, programming in “C/C++” including input/output, control statements, operators, functions, arrays, strings, classes, objects, inheritance, pointers, references, file processing, exceptions and operator overloading; brief introduction into MATLAB; design of algorithms for applications that are relevant for biomedical engineering applications.

## Course Content

### Content Details:

This course teaches students:

- Computer architecture
- Algorithms
- Overview of C/C++
- Constants, Variables, Data Types
- Operators and Expressions
- Control Structures, Loops and Arrays
- Modules and Functions
- Pointers and references
- Classes and objects
- Friendship and inheritance
- Outlook to other programming languages – MATLAB

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Have a basic understanding of computer hardware and architecture.
- Understand how a computer stores and processes integer and floating-point numbers as well as char and string variables.
- Understand binary and hexadecimal number systems.
- Comprehend and apply different programming statements, including if, for, while, else, switch
- Deal with string operations and basic handling of database operations.
- Solve mathematical problem by translating them into computer codes.
- Write simple programs to solve BME related problems

### Course (Student) Learning Outcomes Assessment Measures:

**Quizzes:** **Counts 10% towards the final grade calculation**

There will be between 6 to 8 short quizzes. The number of quizzes and the exact date for these quizzes will not be announced in advance. Each quiz starts at the beginning of class, 10 am sharp, and has a duration of 5 minutes. ***The lowest quiz grade will be dropped. There will be no makeup for any missed quiz. Arriving after 10 am for a lecture is not a valid excuse for missing a quiz.***

**Homework Assignments: Counts 30% towards the final grade calculation**

There are ***10 homework assignments***, typically one every week from week 2, which contain programming tasks and understanding type-questions based on the material that has been covered in class up to that point. ***Each homework submission needs to be submitted via LMS on or before the due date (which is typically one week after the homework assignment was made available). Late submissions will not be accepted and receive a grade of zero unless a valid and verified excuse can be produced*.**

**Midterm 1: Counts 15% towards the final grade calculation**

The test format includes the following 4 problems: (i) fill in the gaps, (ii) finding errors, (iii) interpret a given code and (iv) write a small C program. The test is scheduled for ***Thursday,* *October 10th, 2024 during class time for a duration of 80 minutes. If a student is unable to participate in this test due to a valid and verified excuse, the percentage of the Final Examination will substitute the grade for Test 1. If no valid excuse can be produced, the missed midterm exam will be graded as zero. There is no makeup for Test 1!***

**Midterm 2: Counts 15% towards the final grade calculation**

This test is scheduled for ***Monday, November 25th, 2024, during class time for a duration of 80 minutes.*** The test format includes the following 4 problems: (i) fill in the gaps, (ii) finding errors, (iii) interpret a given code and (iv) write a small object-oriented program in C++. ***If a student is unable to participate in this test due to a valid and verified excuse, the percentage of final Final Examination will substitute the grade for Test 2. If no valid excuse can be produced, the missed midterm exam will be graded as zero. There is no makeup for Test 2!***

**Final Examination: Counts 30% towards the final grade calculation**

The final exam is scheduled ***during Finals Week (December 13th to 19th) for a duration of 120 minutes***. The final exam includes the problems of the type: (i) fill in the gaps, (ii) finding errors, (iii) interpret a given code and (iv) write a small program. Problems will relate to all programming languages covered in this course, *i*.*e*. C/C+ as well as MATLAB.

## Grading Criteria

### Criteria Details:

- **Test 1 (15%):** Based on C programming (fill the gaps, find errors, interpret a given code, write code for a particular problem) on October 10th, 2024, during class time.

- **Final Examination (30%):** Includes similar problems to Tests 1 and 2, related to C/C++ and (fill the gaps, find errors, interpret a given code, write code for a particular problem) for MATLAB. The final examination is during finals week.

- ### Academic Integrity

  Student-teacher relationships are built on trust.
