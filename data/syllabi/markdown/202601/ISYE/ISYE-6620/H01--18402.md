## Course Description

### Additional Course Description :

A thorough development of a simulation language is stressed in order to progress through a series of increasingly sophisticated applications of computer simulation. Projects cover a wide range of topics: production systems, inventory, finance, transportation, and public systems. The course includes model development, statistical analysis of simulation input/output data, validation planning, and managing simulation projects.  
**Credits Allocated:** 3 semester hours

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Identify appropriate real manufacturing and service systems to be modeled using discrete event simulation (DES)
- Determine and quantify appropriate system goal(s) for such systems
- Use abstraction to create a simplified, yet applicable system model to be used in DES
- Use the simplified model to create a representative model in AnyLogic
- Run discrete event simulations in AnyLogic of the simplified model AND appropriately apply statistical methods to: -- select the appropriate statistical distribution to describe variation within the system; -- analyze the results; -- create quantitative measures of how well the system goal is met.\* -- \*Notice that these outcomes are all stated together. Without the ability to properly apply statistical methods, analyze the results, and make conclusions, results are meaningless and can even lead to incorrect conclusions and/or decisions.
