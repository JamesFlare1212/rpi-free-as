## Course Description

### Additional Course Description :

The primary objective of this co-listed course is to provide the student with knowledge and hands on training of technologies that manipulate data at the various organizational levels such as the structured query language (SQL), extraction transformation and loading tools (ETL), data warehousing (DW), and online analytical processing (OLAP).

## Course Goals

### Goals:

- Define the role of data in an organization and the life cycle of a data project.
- Analyze a business problem and create process models.
- Learn how to query a database using SQL
- Learn how to build operational (OLTP) and analytical (OLAP) databases.
- Learn how to use database techniques to provide advanced reporting capabilities.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Create Entity-Relationship diagrams
- Create operational models from entity-relationship diagrams
- Create dimensional models from operational models
- Create analysis models from dimensional models
- Create dashboards and visualizations

### Course (Student) Learning Outcomes Assessment Measures:

Test 1: Business Analysis

Percent of course grade: 20%

Students will be given a business process and will be required to build a Business Process diagram and an Entity-Relationship diagram.

Test 2: SQL Queries

Percent of course grade: 20%

Students will be given an Entity-Relationship diagram and will be required to build an On-Line Transaction Processing (OLTP) database.

Test 3: Data Warehousing

Percent of course grade: 20%

Students will create a Data Warehouse from the OLTP database.

Test 4: Advanced Data Management

Percent of course grade: 20%

Students will build dashboards in Excel and PowerBI from the Data Warehouse

Final:

Percent of course grade: 20%
