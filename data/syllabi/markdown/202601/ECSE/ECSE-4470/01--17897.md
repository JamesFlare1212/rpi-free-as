## Course Description

### Additional Course Description :

This course provides an introduction to Robot Operating System (ROS), a widely used middleware for robot programming. Students will learn the basic components of ROS, how to utilize and write ROS packages, gain experience utilizing simulation software, and apply the concepts to physical platforms.

## Course Text(s)

### Text Details:

## Course Goals

### Goals:

Students who complete this course satisfactorily will be able to:  
(1) Navigate and utilize a Linux system (Ubuntu)  
(2) Apply the basics of Python programming to create ROS communication capable code  
(3) Identify ROS components such as nodes, topics, services, actions, launch files, etc. and explain how they differ between ROS1 and ROS2  
(4) Apply ROS components knowledge to write and utilize ROS packages to achieve a specific task  
(5) Successfully test developed code using simulation tools (Rviz, Gazebo)

## Course Content

### Content Details:

Major Topics Covered: Students who complete this course satisfactorily will be able to understand and apply the following: (1) Linux system command line usage (2) ROS components (3) ROS packages (4) URDF files (5) Rviz (6) MoveIt! (7) Gazebo (8) ROS1 vs ROS2 (9) Application to real systems
