## Course Description

### Additional Course Description :

Machine learning (ML) has become a powerful tool in engineering and sciences, enabling data-driven discovery, prediction, and interpretation of complex physical phenomena and properties. This course provides *a hands-on introduction to applied ML* with a focus on problems in chemical and materials engineering, but also other disciplines. Students will learn how to build, evaluate, interpret, and communicate ML models using Python, with an emphasis on scientific insight rather than black-box prediction only. The course is *project-centered* and *exam-free*, combining lectures with in-class hands-on practice sessions. No prior programming or machine learning experience is required.

## Course Text(s)

## Course Goals

### Goals:

Machine learning is a powerful tool, but not a replacement for physical understanding. This course emphasizes **critical thinking**, **interpretation**, and **responsible use** of ML in engineering and sciences.

## Course Content

### Content Details:

- Python programming for data analysis
- Data handling, visualization, and preprocessing
- Regression and classification
- Model evaluation and validation
- Tree-based models and ensemble methods
- Unsupervised learning (PCA, clustering)
- Feature engineering and representations
- Introduction to deep learning (neural networks)
- Model uncertainty and generalization
- Model interpretation and explainability
- Reproducibility and best practices in ML for science

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Implement machine learning (ML) workflows in Python for chemical, materials, and related datasets
- Choose appropriate representations (features) for physical systems
- Train, validate, and interpret ML models
- Apply ML responsibly, understanding uncertainty and failure modes
- Communicate ML-driven scientific insights effectively
- Gain experience in Python programming

### Course (Student) Learning Outcomes Assessment Measures:

The course learnings will be assessed through open-response questions on individual and group assignments, and projects. In these assessment methods:

- *Conceptual Understanding*: Students will demonstrate understanding of core ML concepts by explaining model choices, assumptions, limitations, and results in written responses.
- *Problem Solving*: Students will formulate and solve data-driven chemical and materials engineering problems by selecting appropriate ML approaches and justifying their decisions based on problem context and data characteristics.
- *Computational Modeling*: Students will implement, train, validate, and interpret ML models using Python, demonstrating correct use of computational workflows and best practices.
- *Case Studies*: Students will analyze real-world datasets through guided case studies, evaluating model performance, generalization, and scientific relevance.
- *Collaborative Skills*: Students will work effectively in teams to design, execute, and communicate ML projects, demonstrating shared responsibility, constructive feedback, and collaboration.

## Other Course-Specific Information

### Additional Course Information:

**Coding**  
*No prior programming experience is required*. However, by the second week of the course, students are expected to be able to read and write simple Jupyter/Google Colab notebooks. This includes using imported Python modules, calling straightforward functions, and having a working understanding of basic Python data structures such as dictionaries and pandas DataFrames. By the fourth week, students should begin to feel comfortable writing Python code to load data, parse data, and perform basic operations on that data. Some course material will involve interactive coding during class, so students are expected to bring a laptop to all class sessions, especially the studio sessions.  
**AI Use Policy**  
Please know that LLMs (e.g., ChatGPT, Gemini etc.) are **allowed** to aid in code writing with the following caveats: (1) You are responsible for the correctness of the work, and (2) Most popular LLMs are proficient at *writing code that runs*, not necessarily *code that does what you want it to*. I would suggest using these models to build scaffolds of code and amend it to your purpose. LLMs are also very good at diagnosing bugs and explaining logic and function of code blocks. Becoming overly reliant on LLMs is strongly discouraged (you simply won't learn as much or develop an intuition to solve problems).  
**Expectations and Classroom Norms**

- Laptops are expected and encouraged
- Collaboration is encouraged; submitted work must be your own
- Focus on understanding, not optimization alone
- Struggling with code is part of learning -- ask questions early
