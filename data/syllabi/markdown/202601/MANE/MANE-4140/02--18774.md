## Course Description

### Additional Course Description :

This course provides an understanding of computational methods used in fluid dynamics, and hands-on experience in solving complex flow problems. Students will learn about computational fluid dynamics methods (finite volume method), write code, solve benchmark problems, and analyze the stability and convergence of algorithms. They will use CFD packages to solve problems motivated by complex engineering applications, learn how to represent geometry, mesh fluid volumes, and select models for turbulence.

## Course Goals

### Goals:

This course introduces the student to computational methods used to study fluid flow problems. We will explore fundamental numerical methods used in the solution of partial differential equations and write code to implement simple solution algorithms. We will also explore solution methods for benchmark fluid flow problems through the use of a CFD software package, learning how to appropriately setup the problem (computational mesh size, boundary conditions, solver settings, model selection, etc.) and assessing accuracy through verification and validation.

## Course Content

### Content Details:

- Review of conservation equations
- Introduction to computational methods
- Numerical methods to solve PDEs
  - o Central differencing, upwinding, etc
  - o Time discretization: explicit and implicit methods
  - o Boundary conditions
  - o Convergence of a numerical method: accuracy and stability
- Utilization of a CFD software package to solve complex fluid flow problems
  - o Turbulence modeling: popular RANS, DES and LES approaches
  - o Meshing for boundary layers
  - o Post-processing methods
  - o Verification and validation of results

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Students will learn the basic principles of computational fluid dynamics, including numerical methods, discretization, convergence, accuracy, and stability.
- Students will learn the fundamental concepts of numerical solutions to differential equations and how to apply these concepts to the solution of simple fluid flow problems.
- Students will be able to use a CFD software package to solve benchmark engineering problems in the mechanical, aerospace, and nuclear engineering fields.
- Students will be able to assess mesh convergence, choose appropriate time stepping and turbulence modeling methods, account for boundary layers, and validate results from a CFD analysis.
- For MANE 6140 only: Students will be able to make additions and/or modifications to models within a CFD software package to more accurately or effectively solve specific fluid flow problems.

### Course (Student) Learning Outcomes Assessment Measures:

Assignments and a course project will be used to assess the students learning for each of the Course Learning Outcomes.
