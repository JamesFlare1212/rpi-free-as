## Course Description

### Additional Course Description :

This course goes far beyond the classical statistical methods, such as linear regression, that are introduced in ECON4570/6560 (Econometrics/Introduction to Econometrics). It aims to provide an overview to such modern non-linear methods as Generalized Additive Models, Decision Trees, Boosting, Bagging and Support Vector Machines as well as more classical linear approaches such as Logistic Regression, Linear Discriminant Analysis, K-Means Clustering and Nearest Neighbors.  
This course will cover all of these approaches in the context of Marketing, Finance and other important business decisions. At the end of this course you should have a basic understanding of how all of these methods work and be able to apply them in real business situations. With the explosion of Big Data problems, statistical learning has become a very hot field in many scientific areas as well as marketing,  
finance and other business disciplines.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Students will be able to demonstrate understanding of conceptual underpinnings of methods in statistical learning, more specifically, how statistical learning works and review the underlying statistical framework. Students will be able to show proficiency in: (a) A wide variety of statistical learning methods, including Generalized Additive Models, Decision Trees, Boosting, Bagging and Support Vector Machines as well as more classical linear approaches such as Logistic Regression, Linear Discriminant Analysis, K-Means Clustering and Nearest Neighbors (b) Evaluation the performance of these learning methods. (c) Applications of these learning methods to real problems
