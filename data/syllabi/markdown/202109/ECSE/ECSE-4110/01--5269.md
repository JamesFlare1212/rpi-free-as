## Course Description

### Additional Course Description :

## Course Description

AC steady-state analysis, three-phase networks, and complex power (brief review). Per-unit system. Practical transformer equivalent circuits. AC power transmission-lines: parameters; equivalent circuits; and steady-state operation. Power flow with transfer limits in balanced three-phase systems. Network power flow problem with solution by numerical methods. Symmetrical components: analysis including sequence networks for three-phase systems. Fault analysis.

## Course Goals

### Goals:

# *Course Intended Learning Outcomes (ILOs)*

After completing the course, the students should be able to:

Using first principles, derive the basic concepts and methods used for power system analysis.

1. Describe the methods used for modeling and simulation of different power system phenomena, and
2. Explain how numerical methods affect the modeling process

Construct mathematical models for computing the steady state performance, basic unbalanced performance and dynamics of power systems.

Be able to model different components used in power network.

Using different methods, analyze, and reflect on the performance of a power system under steady state and unbalanced operation, for transmission and distribution networks

Apply a power system and/or general purpose software tools, such as MATLAB, to analyze the performance of a power system, and evaluate it for different operating conditions

Reflect broader factors related to electrical power grids such as policy, regulation and innovation in technology.

For graduate students (MSc and PhD), to pass the course, and for undergraduate students to attain a B+ or higher, they need to fulfill the following additional Intended Learning Outcomes:

1. Contrast different software aspects (e.g. tools and software development methods) that are used in the creation of software used in power systems.
2. Analyze a technical solution for a specific power system analysis.

## Project (Graded)

Summary of the Project:

The goal of the project is that you fulfill the “Student Intended Learning Outcomes” by solving a problem using the course concepts and a software tool.

Your project submission will consist of:

1. A report, documenting all of your results and analysis.
2. A presentation summarizing your report, and highlighting your main findings.

**Selecting the project topic:**

- (a) Both 4110 and 6110 students will have the option of proposing a project topic that has to be approved by the instructor. Otherwise they have to carry out a project assigned by the instructor.
- (b) The project scope and rigor is expected to be higher for 6110 students that has to be approved by the instructor after reviewing the project proposal.

The project will be graded based on the efforts, approach adopted, the results and presentation.
