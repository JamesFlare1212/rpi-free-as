## Course Description

### Additional Course Description :

Introduces fundamentals in AI-based methods directly applicable to protect and enhance performance of industrial systems. Learning methods for modelling systems with data, model order reduction with deep learning, extreme learning machines, reinforcement learning algorithms and their deep architectures are included. Application examples for modeling & detecting cyberattacks are covered. How to design a discrete reinforcement learning without knowing full system dynamics of the control system will be introduced with examples.

## Course Goals

### Goals:

To systematically learn AI-based methods for securing control systems against cyberattacks. Applications include medical device(s) and/ control system(s) with many real-world examples.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

No Course Learning Outcomes are available for this course.

### Course (Student) Learning Outcomes Assessment Measures:

1. Apply mathematical fundamentals such as linear matrix algebra & calculus, singular value decomposition, principal component analysis, regularization, data normalization and validation methods for designing AI learning algorithms specifically suited for biomedical & industrial control systems.
2. Demonstrate an ability for modeling systems with input-output data, decompose the system into features with autoencoders and/ convolutional neural networks and significantly reduce the order of the dynamic system model to enhance performance.
3. Demonstrate an ability to apply extreme learning machines for detecting cyber-attacks and protecting control systems.
4. Demonstrate an ability to design a discrete reinforcement learning system (an actor-critic control system) with measured signals in real-time using sensors and without knowing full system dynamics of the control system.

## Grading Criteria

### Criteria Details:

Course assessment will be done through homeworks, one midterm exams, one final exam and a final project. Homeworks will mostly consist of quantitative problems, but also include a few matlab-based programming assignments that requires coding simple algorithms. The two exams will be open book, open notes, and time-limited, and will be conducted during the class hours. For the final project, the students can work individually or in teams to apply one of the techniques learnt in the course to a real-life application. The topic of the project needs to be chosen by week 5, and in agreement with the instructor. The final project demo/presentation will be held in the last week of classes.

The details of the grading policy are provided below.

1. Homework assignments 30%
2. One midterm exam 25%
3. One project (computer simulation) 15%
4. Final exam 30%
