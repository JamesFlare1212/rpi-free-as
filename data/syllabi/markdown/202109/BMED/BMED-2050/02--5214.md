## Course Description

### Additional Course Description :

Introduction of number systems – decimal, binary and hexadecimal –; variable types including

Boolean, integer, float, character and string; general overview of computer architecture and

software, programming in “C/C++” including input/output, control statements, operators, functions, arrays, strings, classes, objects, inheritance, pointers, references, file processing, exceptions and operator overloading; brief introduction to other programming languages including Matlab and Python; design of algorithms for applications that are relevant for biomedical engineering applications.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- • Have a basic understanding of computer hardware and architecture.
- • Understand how a computer stores and processes integer and floating point numbers as well as char and string variables.
- • Understand binary and hexadecimal number systems.
- • Comprehend and apply different programming statements, including if, for, while, else, switch.
- • Deal with string operations and basic handling of database operations.
- • Solve mathematical problem by translating them into computer codes.
- • Write simple programs to solve BME related problems.

## Policies

### Attendance Policy:

**Office hours:**

All ***office hours are conducted via WebEx*** during the hours as listed on page 1, along with the WebEx room of both instructors and the TAs.

**Compiler:**

Throughout the course, we will be ***using the online compiler “Replit”***: https://replit.com/~. During the ***first week, create an account*** so that you can participate in practicing coding in class and work on the homework assignments. ***Replit can compile both C++ and Python*** programs.

**Attendance:**

As each lecture is offered in-person, attendance is highly recommended. For a successful completion of this course, ***it is essential to review the course material and the codes we develop in class***.

**Grading concerns:**

All graded homework submissions and examinations are graded on LMS (feedback will be provided). If there are any questions or concerns, ***there is a one-week window after each homework assignment or the midterm examination has been graded to seek clarification during the TA office hours. It is important to note that any issue that has not been brought to the attention of the TA one week after a homework assignment or the midterm exam was graded is not going to be considered.*** The grades for each homework assignment and the grades for the midterm and final examination will be uploaded on LMS.

### Academic Policies:

- ### Academic Integrity

  Student-teacher relationships are built on trust. For example, students must trust that teachers have made appropriate decisions about the structure and content of the courses they teach, and teachers must trust that the assignments that students turn in are their own. Acts that violate this trust undermine the educational process. The Rensselaer Handbook of Student Rights and Responsibilities and The Graduate Student Supplement define various forms of Academic Dishonesty and you should make yourself familiar with these.
