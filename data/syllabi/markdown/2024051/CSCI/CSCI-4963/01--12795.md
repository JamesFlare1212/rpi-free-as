## Course Description

### Additional Course Description :

Java is one of the most popular general purpose modern programming languages used in industry. This course focuses on learning and practicing advanced Java features which are widely used in industry and research. The first part of the course is dedicated to object-oriented features of Java and how to use them in software design. It also covers all major tools that support the development process during the entire software development life cycle. The second part of the course covers parallel programming, how it can be implemented in Java, its advantages, and limitations. The third part of the course is dedicated to creating Web applications. Finally, the fourth part of the course discusses different database models and provides specific details on how to create Java applications that can use different databases as a data storage option. Special attention is given to noSQL graph databases which combined with Java allow building solutions that are capable of storing, manipulating, and analyzing billion-node scale networks.

## Course Goals

### Goals:

The goal of this course is for students to develop both theoretical understanding and hands-on practical experience in using all major advanced features of Java SE (versions 8 and up) and Java EE (versions 5 and up) programming language enabling them to understand existing and to create their own Java code to solve a wide range of common real-world problems. Special attention is given to designing rich GUI applications, as well as network enabled and high performance solutions. Basic features of Spring Boot framework are covered in the context of creating Web applications. Designing and implementing data-centric applications is introduced with the JDBC library and noSQL graph database Neo4j.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Demonstrate competence using any Java SE language features and major JDK libraries to create console and rich GUI applications.
- Analyze user interfaces (UI) from the usability and ergonomics perspectives, design industry-grade UI for real-world applications, and implement them in Java SE code using JavaFX library.
- Apply knowledge of the design of network-enabled applications to create practical and efficient real-world client-server software.
- Have a working knowledge of high performance computing features offered by Java and apply this knowledge in creating robust multithreaded applications.
- Have a working knowledge of the major concepts related to creating real-world Web applications and apply this knowledge to design, build, and deploy Java EE and Spring Boot projects.
- Apply major database concepts for both SQL and noSQL database systems to design and implement data-driven Java SE applications.
- Analyze and plan specific communication scenarios, including selecting the purposes for effective communication and targeting specific audiences by preparing proposals, including discussions of results achieved by others, planning own testing and experiments, and reporting own results.

- Identify and apply appropriate genre and design conventions, such as language, images, graphics, typography, organization, and tone in two oral presentations (one individual and one team-based).

## Grading Criteria

### Criteria Details:

The final course grade is composed of the following:

· Participation - 20%

· Homework assignments - 40%

· Article review (5%) and presentation (5%).

· Final team project - 25% (15% implementation, 5% written report, and 5% presentation)

· Participation in peer grading experience - 5% (awarded if completed 80% or more of the assigned peer grading, 0 otherwise). Completing a peer grading assignment implies leaving detailed, well structured, and meaningful written comments regarding the work being reviewed. Note, the peer grading component is subject to availability of the peer grading feature on Submitty.

Final letter grades will be assigned as follows:

| **Letter** | **Grade Range** |
| --- | --- |
| A | [93-100] |
| A- | [90-93) |
| B+ | [87-90) |
| B | [83-87) |
| B- | [80-83) |
| C+ | [77-80) |
| C | [73-77) |
| C- | [70-73) |
| D+ | [67-70) |
| D | [60-67) |
| F | [0-60) |

The thresholds are guaranteed to not be raised from the ones given above but they may be lowered. All grades are rounded only before applying the cutoffs. Rounding is performed to the nearest 0.01 using the bankers' rounding method. Cutoffs may end up lower than this but will not be raised from here. Thus, for example, if you earn 92.9950 it is rounded to 93.00. After applying the cutoff of 93, you are assured of earning an A, regardless of what other students earn. If your average grade is 92.9949, it is rounded to 92.99. If the cutoff for an A is 93, you will get an A-.  
Any grade inquiries will only be accepted if filed within seven calendar days after the grades have been made available to students.

### Additional Academic Integrity Course Policy and Penalty Information:

Assignments must be completed individually. Any part of the work that has been created by someone else (e.g., using a library function, API, or framework) must not constitute more than 10% of the entire assignment or project and must be clearly attributed. Referencing or reusing any work created by someone else must be permitted by relevant licenses and comply with all applicable laws and regulations. We encourage discussion, however, carrying out material (e.g., photos, writing) from a discussion is not allowed. The actual work must be your own. Submitty has advanced plagiarism detection capabilities, which we will use on every homework assignment.  
If found in violation of academic dishonesty policy, students will be subject to two types of penalties: (1) the instructor administers an academic (grade) penalty; and/or (2) the student may be subject to the procedures and penalties of the student judicial system outlined in the Rensselaer Handbook of Student Rights and Responsibilities. **Excessive similarities between different submissions, including past semester submissions, will result in a grade of zero for the corresponding assignment or project in addition to one letter grade penalty for all students involved. Even if a violation only affects a part of the assignment, quiz, or project, the entire gradeable will be set to zero. A subsequent infraction will result in an automatic grade of F for the course.** Each incident will be reported to the Dean of Students and the Department Head. Cheating may cause a student to become ineligible to mentor for the department, participate in departmental organizations, etc.  
For team-based work (though working in a team is optional), work must be the sole work of the individual team members, though the instructor, TAs, and undergraduate mentors may help in figuring out how to solve the given problems.

Scholastic dishonesty means any form of cheating on assignments, quizzes, or projects, including the unauthorized use of online learning support and testing platforms; engaging in unauthorized collaboration on academic work, including the posting of student-generated coursework on online learning support and testing platforms not approved for the specific course in question; taking, acquiring, or using course materials without faculty permission, including the posting of faculty-provided course materials on online learning and testing platforms.  
Artificial intelligence (AI) language models, such as ChatGPT, and online assignment help tools, such as Chegg®, are examples of online learning support platforms: they can not be used for course assignments, quizzes, projects, or any other activities except as explicitly authorized by the instructor. The following actions are prohibited in this course:

- Submitting all or any part of an assignment statement to an online learning support platform;
- Incorporating any part of an AI generated response in an assignment;
- Using AI to brainstorm, formulate arguments, or template ideas for assignments;
- Using AI to summarize or contextualize source materials;
- Using AI to generate code;
- Submitting your own work for this class to an online learning support platform for iteration or improvement.

**If you are in doubt as to whether you are using an online learning support platform appropriately in this course, I encourage you to discuss your situation with the instructor. Any assignment content composed by any resource other than you, regardless of whether that resource is human or digital, must be attributed to the source through proper citation. Unattributed use of online learning support platforms and unauthorized sharing of instructional property are forms of scholastic dishonesty and will be treated as such.**
