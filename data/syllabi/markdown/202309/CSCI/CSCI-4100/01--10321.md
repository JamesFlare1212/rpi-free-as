## Course Text(s)

### Text Details:

Text Book: Learning From Data by Abu-Mostafa, Magdon-Ismail, Lin.  
Introduction to the theory and applications of Machine Learning From Data. The rough outline is:  
1\. Foundations  
(i) The Learning Problem: What is learning?  
(ii) Training Versus Testing: Can we learn?  
(iii) The Linear Model : How to learn?  
(iv) Overfitting: How to learn well?  
(v) Three Learning Principles: Lessons learned: Occam; sampling bias; snooping.  
2\. Techniques (we will cover a few)  
(vi) Similarity Based Methods  
(vii) Neural Networks  
(viii) Support Vector Machines  
(ix) Aggregation Methods: methods for combining models.  
(x) Learning Aides: methods for improving the performance.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Understand what it means to learn from data.
- Formulate a learning problem precisely, in terms of inputs and outputs
- Describe the basic tools for learning from data.
- Understand the limits to which information can be learned from data.
- Understand the basic tradeoffs in learning from data.
- Understand the general pitfalls when learning from data.
- Implement, as well as critique basic models for learning from data.
- Select a learning model and algorithm, run it on the data, and interpret the results.
- Provide some measures of how effective the learning was.

### Course (Student) Learning Outcomes Assessment Measures:

Homework assignments will be assigned to measure a students understanding of the theoretical foundations and ability to implement and deploy learning models.
