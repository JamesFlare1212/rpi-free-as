## Course Description

### Additional Course Description :

## The goal of the course is to introduce the students to commonly used numerical methods and algorithms in uncertainty quantification (UQ), especially in the context of performing parameter estimation/calibration, validation and predictions for models composed of differential equations. Techniques dealing with representation and propagation of uncertainties will be covered including implementation details. Topics will include: probabilistic/statistical modeling; model form uncertainty/inadequacy; statistical inversion/parameter estimation/calibration (inverse propagation); Bayesian inference (priors and posteriors); model ranking and validation; sampling techniques/Monte Carlo methods; spectral methods including polynomial chaos-based methods such as stochastic Galerkin and stochastic collocation with sparse grids; and surrogate modeling.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- 1\. Students should be able to formulate and correctly use the basic principles of uncertainty quantification: probability concepts, numerical techniques including sampling, parameter estimation/calibration, forward propagation, sensitivity analysis and reduced-order/surrogate modeling
- 2\. Students should understand and apply computational concepts such as random sampling, grid-based sampling, polynomial chaos-based methods such as stochastic Galerkin and stochastic collocation with sparse grids, and surrogate modeling.
- 3\. Students should able to independently use software package(s) to solve relevant engineering problems involving uncertainty quantification.

**Project (40%)**:

The course emphasizes on a single project. The project must involve (at least) a technique/method for uncertainty quantification of a system driven/modeled by differential equation(s). The project can be based on literature review (e.g., on a research topic in UQ) and/or code development (e.g., implementation of method for UQ). *Note that projects with only application of an existing UQ code/package to a problem – without any new implementation or development(s) – will NOT be accepted*.

**The project submissions (both midterm and final) must include basic formulation and details of the specific topic(s) and/or aspect(s) that is the focus of the project. Similar format is expected for project presentation. Further details will be discussed on individual basis.**
