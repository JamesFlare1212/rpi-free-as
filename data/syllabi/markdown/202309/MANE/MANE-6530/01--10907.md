## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- We expect students to be able to manipulate the Navier-Stokes equations in tensor form along with continuity equation.
- We expect the students to have basic analytical skills to examine how hydrodynamic instabilities manifest and ultimately lead to turbulence. Specifically, we expect students to have the analytical skills to consider a shear flow with a set of piecewise linear velocity profiles and be able to predict if any range of wave numbers are unstable.
- We expect students to be able to determine scaling relations for turbulent flows of various types (free shear vs those next to solid walls).

### Course (Student) Learning Outcomes Assessment Measures:

two midterm exams will be given along with a comprehensive final exam. Also, approximately six homework assignments will be given and graded
