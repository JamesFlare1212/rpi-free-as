## Course Description

### Additional Course Description :

The course provides an accelerated introduction to prevalent programming languages and constructs, graphics libraries and development environments. The course spans from an introduction to the basic concepts of general programming, object oriented programming and 2D graphics through basic web design, 3D graphics on the web building data modeling and web database integration. This class is oriented to students who are interested in going beyond simply using 2D and 3D programs, who want to better understand the technologies behind these tools, and access capabilities beyond those of simple scripting. Students develop a web based design modeling application targeting their domain of design interest over the course of the semester, as well as learning technical skills through weekly exercises.

## Course Goals

### Goals:

Design Programming 1 provides an accelerated introduction to computer programming for design professionals including instruction in 2D and 3D graphics, Web applications, and building data.

## Course Content

### Content Details:

Module 1: 2D Graphics Programming

1. **Introduction to Processing**

- Introduction to the Processing Interactive Development Environment (IDE)
- 2D canvas and pixel coordinates
- 2D Primitives: rect, ellipse, line, point, shape / vertex
- Graphics state
- fill / noFill, stroke / noStroke, strokeWeight, etc.
- image placement
- **Assignment #1:** Draw a picture using processing

1. **Java / C Language Programming Basics**

- Basic syntax
- Variables and Types
- Conditionals
- Loops
- Arrays
- Animation
- **Assignment #2:** Automated drawing, animation

1. **Object Oriented & Event Based Programming**

- Euclidean: mirror, move, rotate, orient
- Affine: scale, project
- Morph: surface, box, twisted box, map to surface
- **Assignment #3:** Design elements with interactions

1. **2D Geometry Programming 2**

- **Curves**
- **Transforms**
- **Assignment #4: Add transformations to design elements**

Module 2: Client Side Web Development

1. **Basic Web Data**

- ○ Document Object Model
- ○ HTML
- ○ CSS
- ○ Visual Studio Code IDE
- ○ **Assignment #5:** Make a small personal web site

   - ○ Language differences vs. Java

   - ○ **Assignment #6:** Input forms and scripts exercise
   - ○

7. **P5.js Processing Javascript library**
   - ○ js

   - ○ **Assignment #7:** Hack an interactive 2D web graphic project

8. 3D Web Graphics Basics
   - ○ js
   - ○ Scenes, objects, lights, etc.
   - ○ Basic objects
   - ○ **Assignment #8:** Create a scene with 3D elements and controls

9. 3D Web Graphics II
   - ○ js continued
   - ○ Materials

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Have an understanding of core 2D and 3D computer graphics and geometry
- Know a broad set of basic and mid level computer programming paradigms
- Gain experience and familiarity with several standard computer programming languages
- Understand key desktop and web interaction and dynamic programming paradigms
- Be able to develop complete simple desktop and web client-server applications
- Gain familiarity with standard 2D and 3D graphics libraries

### Course (Student) Learning Outcomes Assessment Measures:

- Weekly homework assignments - each assignment provides detailed requirements that allow the student to demonstrate they have captured and can use the information provided in the corresponding lectures
- Final semester project - the final brief includes detailed requirements that cover all aspects of the course.
