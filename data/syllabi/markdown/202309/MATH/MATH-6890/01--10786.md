## Course Description

### Additional Course Description :

This course targets the development of parallel algorithms for scientific computing.  
The course will consider the development of parallel computer codes using  
(1) task parallelism with OpenMP,  
(2) distributed memory parallelism with MPI (Message Passing Interface),  
(3) GPU programming with CUDA.  
Target applications will be selected from, for example,  
(1) solution of sparse linear systems,  
(2) solution of time-dependent and time-independent partial differential equations,  
(3) solution of large scale eigenvalue problems.  
Computer codes will be developed using C++ on a Linux workstation.  
Some knowledge of numerical methods for differential equations is assumed.

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- This course targets the development of parallel algorithms for scientific computing applications such as the solution of partial differential equations, the computation of eigenvalues or the solution of linear systems. Upon successful completion of the course you should 1. have an understanding of modern computer architectures and parallel programing paradigms, 2. be able to develop task parallel codes using OpenMP. 3. be able to develop distributed memory parallel codes using MPI. 4. be able to develop codes for GPU's using CUDA. This knowledge will be highly beneficial when developing new software or working with existing software for high performance scientific computing.

### Additional Academic Integrity Course Policy and Penalty Information:

The Rensselaer Handbook of Student Rights and Responsibilities defines various forms of Academic Dishonesty and you should make yourself familiar with these. In the case of problem sets, collaboration between students is encouraged. However, each student must write his/her own solutions and submit his/her own problem sets. Copying someone else’s solution or code is not allowed. In the case of exams, there is no collaboration of any kind permitted. If cheating is suspected, then an explanation will be requested. If the explanation is not satisfactory, then an exam grade of zero will be given and a report will be made to the Dean of Students. Cheating on homework is unacceptble. A grade of zero will be given on the first assignment where a violation is detected. If there is a subsequent infraction the student will receive a grade of F for the course.
