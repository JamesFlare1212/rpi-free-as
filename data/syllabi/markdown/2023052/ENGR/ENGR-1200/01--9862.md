## Course Description

### Additional Course Description :

This is an undergraduate introductory course covering techniques for creating solid models of engineering designs. Topics include 2-D parametric sketching, three-dimensional parametric modeling of parts, visualization of three-dimensional space, and computer-generated design documentation.

## Course Text(s)

### Text Details:

NONE

## Course Goals

### Goals:

1. Students should gain introductory skills necessary to create solid model designs using a parametric modeler.
2. Students should be able to translate conceptual designs to virtual models by understanding 2-D & 3-D spatial relationships of basic geometry.
3. Students will be able to document their engineering designs using a 2-D drafting application.

Portfolio Grade:

*Portfolio* is defined as “the digital collection of **every** student-created file submitted for grade **AND** CAD files obtained through LMS necessary to complete all graded assignments”.

New students to BOX must register for BOX first using: https://itssc.rpi.edu/hc/en-us/articles/360004829931-Requesting-a-Box-RPI-Account

Once registered, access your folder through https://box.rpi.edu/

1. After the first week of class, a portfolio folder titled “rcsid-1200” will appear.
2. This folder is UPLOAD ONLY. Please save your work to your local machine FIRST, before uploading to BOX.
3. Students will NOT have privileges to delete or download files once uploaded. If an errant file is uploaded, students may e-mail the course coordinator for removal.

Students will upload **only their final version** of **each** computer model generated each week for grade. These submissions will eventually become your portfolio.

These assignments will **NOT** be **re-graded** for the purposes of improving a grade, forgiving special circumstances.

Each file present (must be at least half complete) is worth: (30 / N) points, where N = total number of graded assignment files due for the course.

**DO NOT** submit **duplicate** **files** for portfolio submission. If a file already exists within the portfolio folder, it will be counted.

1. If a file is not complete enough to earn portfolio credit, you may upload a newer, more complete version.
2. If uploading an assembly, ALL children parts must be uploaded to accompany the assembly. Please keep all files of the same assembly in the same folder.

**Students MUST include the given assignment names when creating and saving their files. Append drawing part names with “\_dwg1” or “\_dwg”. Append assembly names with “assy”. Incorrectly named files will not be graded.**

1. Some examples of acceptable file naming formats for a sample model, assembly, and drawing file from an assignment named “Blade Hook”:

1. **Model File:** blade hook, blade_hook (ensure there is only a single file type extension “.prt”)
2. **Quiz Files:** quiz_XX and quiz_XX_dwg (where “XX” is the Session number, e.g., 03, 06, 09, 12)

- **Drawing File:** blade hook_dwg.prt, blade hook_dwg1.prt

1. **Assembly File:** assy blade hook.prt, blade hook assy.prt

1. **Never use** the following **characters in file** or **folder name** on **BOX:** { **< , > , : , ; , “ , / , \ , | , ? ,** * }. Doing so may result in a non-grade.

Please refrain from uploading LMS PDF assignments, .ZIP/.RAR/.7z (compressed) folders, videos, or any LECTURE supplement files that you have downloaded.

**It is your responsibility to maintain this data throughout the course. Hard drive crashes, re-images, computer repair slips, etc.** **WILL NOT BE VAILD EXCUSES!**
