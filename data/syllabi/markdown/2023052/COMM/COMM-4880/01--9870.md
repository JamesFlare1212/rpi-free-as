## Course Description

### Additional Course Description :

In this course, you will work in interdisciplinary teams to develop innovative projects using interactive data visualization. Topics include:

- creative problem solving
- problem identification
- audience analysis
- visualization of specific data relationships using different data charts
- effective visual interfaces for an interactive data visualization
- rapid prototyping
- usability testing

## Learning Outcomes

### Course (Student) Learning Outcomes (CLOs):

- Students will critically evaluate the interactive designs of different types of data visualizations to determine the most effective ways to visualize specific data relationships.
- Students will identify appropriate problems to which data can be applied, and discuss limitations, biases, assumptions, and interpretations.
- Students will effectively communicate about problems/issues in this field in which data is a relevant tool, including writing about, presenting on, and visualizing data.
- Students will create a design document for an interactive data visualization. They will identify a problem to address with data analysis, determine the audience and objectives for the project, decide what data relationships meet the objectives, and determine the best forms of data visualization and interaction design to show specific data relationships by applying research and principles in visual design, information and data design, visual perception, and human-computer interaction (HCI).
- Students will develop a prototype for the interactive data visualization program
- Students will test the prototype, evaluate the results, and propose revisions for the interface design.
- Students will analyze peer projects and provide constructive feedback on the projects during class discussions.

## Grading Criteria

### Criteria Details:

**Projects**

In this course you will design an interactive data visualization project. There will be several phases (assignments) in the development of this project. Each assignment is a team project. Class presentations are required as indicated.

1. **Problem Identification and Analysis (20% of final grade)**

This part of the design process is extremely important. You need to identify the problem and the audience for your project. In a class presentation and paper, you will present the **problem identification and analysis** that answers the following questions:

**a) Problem Identification**

Include a brief statement of the problem.

**b) Audience Analysis**

Describe the primary audience (and if applicable, secondary audience).

Include demographics, education, interests, etc. Develop user personas.

Show how the audience impacts the design of the program.

**c) Objectives**

What are your objectives? What data relationships do you need to show to meet your objectives?

*You must complete both the class presentations and the paper in order to receive credit for this assignment. Failure to complete either part of the assignment will result in an “F” for your grade for this project.*

2. **Interaction Design (30% of final grade)**

This phase of the work includes the development and documentation of the interactive design for the project. The paper includes following:

**a) Task Analysis**

- Diagram of the organizational structure of the program and the navigational flow through the program.

- Description of the navigational control in the program.

**b) Performance Objectives**

For each section or node in the task analysis model write a brief statement

(50 words or less) that describes:

- what you want to accomplish
- how you will achieve your goals
- what actions the user will take

**c) Content Outline**

Create a brief content outline for each section or node in the task analysis model that includes:

- list of information in each section
- list of graphics, charts
- description of text (if any)

**d) Visualization of the Model: Wireframes and Storyboard**

Develop wireframes and storyboards for the interactive program using computer graphics (no hand-drawn sketches). You should include representative screen designs from each section. You do not have to include examples of every screen in the program if many of the screens have the same layout and interaction. Be sure to include screens that illustrate the result of specific actions (e.g., pop-up windows or new visual elements appear on the screen). For each screen design include the following information:

- sketch of the screen
- description of data charts, text
- description of design elements (e.g., layout, color, texture, size, contrast, etc.)
- description of interaction and navigation

**NOTE: Each member of the team should develop two data charts that represent different relationships. Each of these data charts should include a list of variables that the user can select to filter the data and show different relationships within the data chart.**

**Before you decide on the final types of data charts to include in the storyboard, you must create at least two different types of charts for each data visualization, so you can see which visualization works best. In the class presentation and the paper, you should include the following:**

- **ALL the charts you created (including the charts you decided NOT to use in the storyboard)**
- **Discussion of the pros/cons of each chart (including the ones you decided not to use)**

***You must complete both the class presentations and the paper in order to receive credit for this assignment. Failure to complete either part of the assignment will result in an “F” for your grade for this project.***

3. **Prototype Development (30% of final grade)**

This phase of the work includes the development of a prototype. The prototyping method and software will depend on the individual project.

4. **Prototype Testing (20% of final grade)**

A separate handout will cover the instructions for the prototype testing. There will be a class presentation and paper on the usability testing for your project.

**Each member of the team should contribute to the assignments. If you experience problems working as a team, it’s important to address the problems as soon as possible.**

**Final Grade**

To summarize, you final grade will be determined as follows:

Problem Identification and Analysis 20%

Interaction Design 30%

Prototype Development 30%

Prototype Testing 20%

In this class I will assign letter grades for each project and the progress reviews. Your final grade will be determined by translating each letter grade into a numerical equivalent based on the following scale: A=4.0, A-=3.67, B+=3.3, B=3.0, B-=2.67, C+=2.3, C=2.0, D+=1.3, D=1, D-=.67, F=0. Your average for the course must be at least 3.67 for an A-, at least 2.67 for a B-, etc.

**All projects must be completed in order to receive a passing grade.**

If you have any questions about your grade at any time during this course, you should see me as soon as possible.
