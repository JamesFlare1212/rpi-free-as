# Course Atlas

Use Bun for dependencies and scripts. This is a Svelte 5 + Vite + TypeScript + Tailwind 4 project.

The official shadcn-svelte skill is installed at [.claude/skills/shadcn-svelte/SKILL.md](.claude/skills/shadcn-svelte/SKILL.md). Read it before editing UI components. The standard .agents and .codex directories in this environment are read-only, so the skill lives in the writable project-level Claude-compatible location.

Never infer exam modality from an online classroom, an absent final-exam slot, a course name, or lack of evidence. Preserve unknowns. Match course ID AND section title; topics course IDs are reused. Historical and undated evidence must never be promoted to Spring 2027 confirmation. Retain contradictions and quiz warnings. Source quotes must remain short. Do not upload complete third-party syllabi.

After data changes run `bun run data:build`, `bun run data:audit`, and `bun test`. After code changes run `bun run check` and `bun run build`.
